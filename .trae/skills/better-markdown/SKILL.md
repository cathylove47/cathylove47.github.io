# Better Markdown Skill

此 Skill 旨在帮助用户重组和格式化 Markdown 内容，使其更加清晰、结构化且易于阅读。

## 适用场景
- 用户提供了格式混乱或未格式化的 Markdown 文本。
- 用户粘贴了网页内容，需要清理格式。
- 用户明确要求“美化”、“修复”或“整理” Markdown 格式。
- 需要统一标题层级、列表样式或代码块格式时。

## 核心能力与规则
1.  **结构优化**：
    - 修复标题层级（如确保 H1 -> H2 -> H3 的逻辑顺序）。
    - 确保文档结构清晰，层级分明。

2.  **列表标准化**：
    - 统一无序列表符号（建议使用 `-`）。
    - 规范有序列表的编号。
    - 确保列表项有正确的缩进。

3.  **代码块处理**：
    - 确保所有代码块使用正确的围栏（\`\`\`）。
    - 必须标注代码块的语言类型（如 `python`, `javascript`, `bash` 等）。

4.  **表格美化**：
    - 对齐 Markdown 表格列，修复损坏的表格结构。
    - 确保表头和内容对齐。

5.  **链接与图片**：
    - 检查并修复断裂的链接语法。
    - 优化图片标签格式。

6.  **排版细节**：
    - **中英文混排**：在中文和英文单词之间增加空格（例如：“在 GitHub 上”）。
    - **标点符号**：正确使用全角/半角标点。
    - **空白管理**：移除多余的空行，段落之间保留一个空行。
    - **引用块**：规范引用块 `>` 的使用。

## 执行步骤
1.  **分析**：首先分析用户提供的 Markdown 文本，识别结构问题和格式不一致之处。
2.  **重写**：应用上述核心能力重写 Markdown 内容。
3.  **保持语义**：确保在调整格式时，不改变原文的语义和核心内容。
4.  **输出**：直接输出优化后的 Markdown 内容。
