ArtiFusion 适合理解掩码约束采样；RestorePath 适合理解邻域条件与共享潜画布。两者的图像补全均不能证明找回了患者真实的被遮挡组织。

下一层看 BigCell 的全局滑窗和 STREAM 的生成空间选择，再用 QC 与染色评价论文检查“图好看”是否对应任务正确。

四个约束：为什么 WSI 上的扩散模型和自然图像不一样

四个约束决定了这条支线的全部方法选择。理解它们，比记住模型名字更有用。

  • 尺度：单张 WSI 可达千兆像素，无法整体训练或整体采样。所有方法最终都要回答“patch 之间怎么接”——LRDM/ZoomLDM 用嵌入网格 + MultiDiffusion 平均，RestorePath 用随机 patch 扩散 + 距离加权插值。
  • 掩码未知：修复需要一个“哪里坏了”的掩码。ArtiFusion 用阈值法、RestorePath 用 GrandQC，都是外部输入；只有 MedIA 2026 那篇把掩码变成无监督产出。这一环常被当成已知条件，实际是复现里最容易失败的地方。
  • “修好”没有唯一答案：自然图像修复可以对像素，病理图上必须对诊断信息。所以这条支线的评估必须同时有感知/分布指标（FID、LPIPS）与病理特征或下游任务指标（CONCH/UNI 相似度、MIL AUC）。
  • 生成即证据：修出来的细胞结构是模型造的，不是切片里原有的。任何把修复结果喂给下游或阅片的流程，都要保留伪影掩码与“此处为重建”的标注。

TASKS / 五个赛道

五个赛道

同一批方法在不同任务上被反复借用。按“它在这个赛道里负责哪一环”来读，比按论文年份读更清楚。

赛道 A

伪影修复（inpainting）

目标：借助可见组织补全受损区域，尽量保留未损区域；是否逐像素不变要检查具体实现。

ArtiFusion → ArtiDiffuser → RestorePath；Two-Stage Residual Diffusion 与 LPFM 扩展去模糊/低层增强。PathoGen 虽用 inpainting，但用于合成病变，应放在赛道 C。

赛道 B

伪影检测与定位（QC）

目标：识别伪影与生成掩码，供修复系统使用；输出分数图、patch 判定与像素 mask 的粒度需分清。

无监督检测—定位—修复流水线、DiffusionQC、Conditioning Noise；Tissue Detection 与本周的 Artifact Segmentation Benchmark 提供前处理和掩码可靠性的证据。

赛道 C

生成与数据增广

目标：造新图、可控反事实或训练数据，而不是恢复患者已知缺损。

LRDM、ZoomLDM → PixCell/CytoSyn → BigCell；STREAM 改为生成 UNI tokens；CHIS、PathoGen、TopoCellGen、CPathOGen 与 Destroy Me 分别控制结构、病变、布局、干预和伪影。

赛道 D

染色与超分

目标：改变染色域或提高分辨率，保持形态并检查诊断语义，不能只凭视觉逼真验收。

HistDiT、StainDiffuser、LPFM、PixCell 的虚拟 IHC；Histo-Diffusion/SuperDiff、S³-Diff 与 flow matching 邻近路线 CAFlow 的超分。

赛道 E

分割监督与表征学习

目标：利用生成先验改善 mask 或模型特征，而非输出一张修复 RGB 图。

CoDiR 修正低置信伪标签；CMD 做 masked-diffusion 预训练；ZoomLDM 的中间特征用于 MIL。TMEvolve 的反应—扩散图演化只作为概念相邻参考。

已入库 49 MICCAI 2026 · 百万像素修复

RestorePath

把修复从 patch 级推到百万像素级：以病理基础模型嵌入为条件，结合随机 patch 扩散、距离加权插值（DWI）与自适应引导尺度（AGS）改善跨 patch 一致性。

方法细节与论文结果
  • 动机数字：TCGA-BRCA 中 63.7% 的 WSI 含 megapixel 级伪影
  • 去 DWI 后 FID_C 29.66 → 110.48（该数据上退化最明显）
  • 下游 MIL：ABMIL 82.3（伪影）→ 90.3（修复），Origin 89.6
  • LPIPS 在 Camelyon16/BACH 上不如 LaMa；不是患者真实组织恢复保证

已入库 56 CVPR 2024 · 生成/增广

LRDM

用自监督嵌入替代逐 patch 人工标注：嵌入经 cross-attention 注入 LDM，再用 MultiDiffusion 平均拼出 1024×1024 大图。

站内精读 → arXiv ↗ 代码 ↗
方法细节与论文结果
  • 条件：HIPT / iBOT / CTransPath（384·768→512 维）
  • 条件消融 FID：无条件 25.62 → HIPT 6.98
  • 增广使 NCT-CRC patch 准确率 93.8→96.27%；TCGA-BRCA 亚型 1% 数据 AUC 0.725→0.812
  • 直训 1024² 每 epoch 300 h vs patch 法 45 h

已入库 55 MICCAI 2023 · 修复

ArtiFusion

首个把 DDPM 用于病理伪影修复的工作：把修复表述为受掩码约束的渐进去噪重采样，只用 2445 张无伪影图像训练。

站内精读 → arXiv ↗ 代码 ↗
方法细节与论文结果
  • Swin-Transformer 全 U 形骨干 + time token 拼接
  • T=250，Adam lr 1e-4，2×RTX A4000
  • L2/MSE 相对 CycleGAN 降 50%+；推理 30.71 s vs CycleGAN 1.065 s
  • 下游 NCT-CRC 分类：伪影 80.3→修复 92.4（ResNet18）

已入库 57 Medical Image Analysis 2025 · 修复 + 合成

ArtiDiffuser

反事实扩散：只重建被伪影扭曲的区域，同时把“合成伪影”当作增广，用一个模型统一两条方向。

站内精读 → DOI ↗ 代码 ↗
方法细节与论文结果
  • Swin 骨干 + 类别引导 MoE + 类别特定 token
  • 掩码加权损失处理区域不平衡
  • 下游一致性正则：原图与增广图预测保持一致
  • 贡献 723 张跨类别标注 patch（首个）

已入库 58 CVPR 2025 · 多尺度生成

ZoomLDM

一个模型管 8 个倍率：条件从单个嵌入升级为“该 patch 覆盖的 20× 嵌入矩阵”，经 Summarizer 压成定长 token，并另训 CDM 让条件可凭空采样。

站内精读 → arXiv ↗ 代码 ↗
方法细节与论文结果
  • 倍率 20×→0.15625×；联合采样到 4096×4096、4× 超分
  • 低倍率 patch FID 13.42 vs 单倍率基线 106.14
  • 4096² 上质量落后（CLIP FID 6.75），但 8 min vs 4 h
  • 自陈弱点：均匀区域可见拼缝、低尺度不引导处细结构不连贯

已入库 59 ICEIC 2026 · 修复（失焦模糊）

Two-Stage Residual Diffusion

第一阶段用截断扩散调度快速出“结构对但糊”的粗修复；第二阶段以粗输出与真值的潜空间残差为条件合成细节。

站内精读 → DOI ↗
方法细节与论文结果
  • 只处理失焦模糊这一类退化
  • 报告指标为 LPIPS 与 CLIP-IQA（感知类，无保真度指标）
  • 两阶段方法的固有风险：粗修复的结构错误无法被第二阶段纠正
  • 正文在付费墙后，站内精读标注为摘要级核验

已入库 60 Medical Image Analysis 2026 · 检测→定位→修复

Unsupervised Artifact Pipeline

把三件事串成一条无监督流水线：HFM 特征上训归一化流得异常热图 → 异常热图 + 无监督语义分割得像素级掩码 → 掩码引导扩散修复。

TIMELINE / 2023—2026

时间线

  • 2023 起点：修复与生成同时出现 ArtiFusion（MICCAI 2023）首次把 DDPM 用于病理伪影修复，只用无伪影图像训练；DiffInfinite（NeurIPS 2023 D&B）用合成分割掩膜作条件 + 并行随机 patch 扩散生成任意大图；PathLDM 的文本条件路线同期出现（WACV 2024 发表，arXiv 2023-09）。
  • 2024 条件化：用自监督嵌入替代人工标注 LRDM（CVPR 2024）证明 SSL 嵌入足以当条件，并把 patch 模型拼成大图；LatentArtiFusion 把修复搬进潜空间，把推理成本压下来。
  • 2025 分化：修复统一化 vs 生成多尺度 vs 生成基础模型 ArtiDiffuser（MedIA 2025）统一修复与合成并加下游一致性正则；ZoomLDM（CVPR 2025）用倍率感知条件把生成推到 4096×4096；PixCell 把生成推到基础模型规模（PanCan-30M，69,184 张 WSI）。
  • 2026 走向系统：掩码自动化、百万像素与检测可靠性 MedIA 2026 的无监督流水线补上“掩码从哪来”；RestorePath（MICCAI 2026）把修复推到百万像素并要求跨 patch 全局一致；ICEIC 2026 的两阶段残差扩散专治细节丢失；DiffusionQC 把检测也做成扩散模型，而 Tissue Detection 那篇指出检测器的假阳性主要来自前处理的组织检测步骤。

EVALUATION / 三处易错点

评估口径：最容易出错的三处

1 · 指标与条件的独立性

RestorePath 条件用 UNI，FID_C 与 Emb Sim 用 CONCH：是不同编码器，不能仅因同属病理基础模型就断言分数必然被美化。共享训练分布或偏好仍需检查。使用条件编码器自身计算相似度时，尤其需要独立编码器、下游任务或人工判读交叉验证。

2 · 合成伪影 ≠ 真实伪影

ArtiFusion 的测试集伪影来自手工合成方法；RestorePath 的验证掩码来自 failure modes / 气泡合成。这两类实验衡量的是“去合成伪影”，真实扫描伪影需要另测。

3 · FID 口径不统一

同一句“FID”在不同论文里可能指 Vanilla / Crop / CLIP 三种（LRDM 的 BRCA 20× 分别是 6.98 / 15.51 / 7.43）。跨论文比数字前必须先对齐口径，否则结论会反向。

修复保真度

可用指标：L2 / MSE / SSIM / PSNR / FSIM / SRE

已知陷阱：偏袒模糊结果；对细胞级错误不敏感

修复感知质量

可用指标：LPIPS / CLIP-IQA

已知陷阱：伪影类型不同结论反转（透光气泡 vs 不透明墨迹）

病理语义一致性

可用指标：CONCH / UNI / CTransPath 嵌入相似度

已知陷阱：与条件编码器同源时失去独立性

是否真的有临床价值

可用指标：下游 MIL 分类/分割 AUC、注意力是否回到病灶

已知陷阱：需与 Detect-and-Discard 对照，否则分不清“修复”与“剔除”的贡献

REPRODUCTION / 读懂 → 复现 → 改进

复现优先级（面向“读懂机制 → 复现 → 改进”）

  1. 第一档 · ArtiFusion：最小闭环。掩码约束重采样（Eq. 2）、Swin 骨干、T=250、两张 A4000；先跑通修复指标，再补下游分类，确认“掩码大小”这一旋钮对结论的影响。
  2. 第二档 · LRDM：条件化骨架。先复现“SSL 嵌入 → cross-attention → 256 patch”，再上 MultiDiffusion 拼 1024²；条件来源消融（无条件 / ImageNet ViT / CLIP / HIPT）是验证机制是否成立的关键实验，成本可控。
  3. 机制扩展 · ZoomLDM / BigCell / STREAM：分别研究倍率条件、全局速度融合、生成表征空间。作者的多卡与大 batch 是实验配置，不是未经测量的最低门槛；用户算力充足，不因训练规模降级这些方法。
  4. 暂不优先：ICEIC 2026（正文付费墙、仅感知指标）与 MedIA 2026 无监督流水线（无公开代码，需从零实现三段式）。两篇适合作为“读机制、找缺口”的对象，而不是第一批评测目标。
  5. 复现切口：CHIS 检查结构初始化与小波调制；PathoGen 区分病变合成和伪影修复；CoDiR 检查 mask refinement 消融；LPFM 对比粗恢复与扩散细化。优先级取决于机制、协议和资源可达性，而非单纯选择最小模型。
