01

实现与设置

DAPS 官方仓库（main 与 legacy 分支）没有 MRI 算子和权重。作者在 DAPS issue #18 说明 CS-MRI 用 InverseBench 的实现，超参见 InverseBench 论文 Table 12；InverseBench Table 4 的 DAPS 数值与 DAPS Table 2 逐位相同，说明是同一套实验。

  • 问题：multi-coil-mri-knee-lmdb，320×320，ESPIRiT 灵敏度图，随机欠采样（mask_seed 0），simulated_kspace=True（由 MVUE 重新生成 k 空间，无噪）。
  • 先验：MRI-knee.pt（416 MB，EDM 的 DhariwalUNet，复数拆两通道，MVUE 上训练）。
  • 数据：CaltechData 公开的测试 LMDB（96 张，2.3 GB）与验证 LMDB（6 张），无需 fastMRI 账号；未下载训练集。
  • DAPS 超参：退火 200 步、扩散 5 步、Langevin 100 步、步长 1.03e-5、τ 1.63e-3（Table 12 MRI Sim. 列），步长衰减 lr_min_ratio = 0.01。DAPS 论文附录没有 MRI 超参。
  • 环境：Python 3.10、torch 2.9.0（InverseBench 要求 ≥2.9）；每张切片约 43 秒，显存峰值 0.55 GB，全集每卡约 70 分钟。

03

为什么第一次全 0

第一次照 InverseBench Table 12 设「step size decay = 1」，即 Langevin 步长不衰减，结果多数切片输出全 0：PSNR 15–17 dB 正是全 0 图的值，测量误差等于 ‖y‖。

逐步记录范数后发现，在 σ=100 的第一个退火步里 ‖x‖ 从 7.6×10¹ 涨到 5×10²⁹，第 61 次 Langevin 迭代变成 inf，algo/daps.py 的 NaN 保护随即返回全 0。用幂迭代测得 4× 掩膜下 λmax(AᴴA)=2.32，数据项稳定要求步长 < 2τ²/λmax ≈ 2.3×10⁻⁶，而 1.03×10⁻⁵ 超了约 4.5 倍。作者在 InverseBench issue #21 贴出的实际配置用的是默认衰减 0.01，所以表里的 1 应为笔误。

改成 0.01 后，同一张验证切片从 15.48 dB 变成 34.12 dB。先验加载、数据归一化（模拟观测与 forward(GT) 一致，GT 的误差为 0）、FFT 约定、torch 2.9 数值精度都逐项排除过。

05

注意事项

  • 要跑满 96 张：前 18 张偏难，平均只有 29.2 dB，只看子集会误判成复现不出。InverseBench 论文写 94 张，作者在 issue #18 确认是笔误。
  • 这组超参处在稳定边界外：200 个退火步中有 79 步的 Langevin 结果被 NaN 保护丢弃（最后一次在第 102 步），剩下 97 步足以得到论文结果。换机器或数值精度可能再次发散。
  • 只做了模拟 k 空间的 CS-MRI；FFHQ 8 个任务的全量评测没做，FFHQ 的小样本走查见 另一页。
