用作者代码与 DPS 的 FFHQ 权重，按默认超参跑 SR 4×、70% 随机缺失 inpainting 与非线性去模糊，每个任务只取一张 256² 图。PSNR 分别为 32.37 / 34.99 / 32.08 dB，与论文 FFHQ 列同量级；其中 inpainting 几乎逐项吻合。但官方脚本按「迭代过程中 PSNR 最高的那一帧」存图并报告，属 oracle 选择，所以这些数字只能说明链路正确，不等同论文指标复现。

01

跑了什么

仓库 sun-umn/DMPlug @ e3101e7，唯一入口 sr_inp_nonlinear.py。权重 ffhq_10m.pt（DPS 发布，Google Drive）。数据用仓库自带 code/data/ffhq/{00000,00001,00002}.png：SR 与非线性去模糊用 00000，inpainting 用 00001。

任务全部走默认值：DDIM 3 步、eta=0、Adam lr=1e-2、测量噪声 σ=0.01、SR 4×、inpainting 掩码概率固定 0.7；SR/inpainting 5000 轮，非线性去模糊 10000 轮（轮数硬编码在脚本里）。非线性去模糊需额外 clone motionblur 与 bkse，按 README 用 GOPRO 权重。

02

环境与改动

原作者 environment.yml 是 py3.8 + cudatoolkit 11.0 + torch 1.7，在 4090（sm_89）上不可用，改为最小改动版本：conda 前缀环境 env/、python 3.10.22、torch 2.1.2+cu118、torchvision 0.16.2。huggingface_hub 必须降到 0.23.5，否则 diffusers 0.26.2 的 cached_download 导入失败。

无算法代码改动：只有环境版本、PYTHONPATH=$R/code:$R/code/bkse（bkse 要求自己的根在 sys.path）与 HF_HOME/TORCH_HOME 指向本地目录。

耗时（4090 D 单卡）：SR 5000 轮约 26–39 min（并行时更慢，单进程约 0.31 s/轮），inpainting 同量级，非线性去模糊 10000 轮约 31 min；单进程 6–7 GB 显存。

05

没跑的部分与局限

  • 只跑 FFHQ、每任务一张图：未跑 CelebA / LSUN-bedroom，未跑 BID 与 BID+turbulence 两条非线性分支（前者需 BlindDPS 权重，后者需 Stripformer），也没有 100 张的评测集均值。
  • 指标口径不是论文口径：脚本保存并报告「迭代中最优 PSNR / 最小 LPIPS」，理论上高于最终输出；论文表格的取值方式需作者确认，所以本次数字系统性偏高。
  • 未验证未知噪声：论文的 DMPlug+ES-WMV 早停在这份推理脚本里没有入口，本次全部用已知 σ=0.01。
  • 无医学数据：全部是 256² 自然图，不能外推到 MRI/CT 的复数域与多线圈设定。
