LEARNED REPRESENTATION-GUIDED DIFFUSION

不用训练巨型模型，
也能让小图块一起画大图。

这篇论文把问题拆成两层：SSL 特征网格决定各处“画什么”，重叠窗口共同去噪决定相邻区域“怎样接起来”。训练只看 256 × 256 图块；推理维护一张共享的大潜变量画布，而不是把独立生成的小图直接贴起来。

01

不是只有“显存装不下”这一个难题

病理切片可以非常大，但把它切成小块后，又遇到了两个问题。第一，每块组织都配一段精细文字或标签，人工标注成本过高；粗粒度癌种标签又不足以描述相邻图块之间的差别。第二，即使每个图块都生成得逼真，独立生成后拼起来，也可能产生接缝、组织结构断裂或不合理的空间布局。

作者的解法不是扩大网络，而是引入一个中间层：自监督视觉特征（SSL embedding）。它是预训练视觉编码器从图像提取的向量，可携带组织形态、纹理等信息，不需要为每个图块手工写描述。把这些向量保留在原始空间位置，就形成大图的条件网格。

这里的“无人工图块标注”不等于从零不需要资源：仍然需要图像、预训练 SSL 编码器，以及训练扩散模型的算力。与 ArtiFusion 不同，本工作的目标是合成图像及数据增广，不是恢复某个患者受损区域的真实组织。

02

训练阶段：让扩散模型学会“把特征画出来”

① 语义条件分支真实图块 I → 预训练 SSL 编码器 → 向量 y。BRCA 20× 使用 HIPT 的 patch-level ViT。
② 图像潜变量分支同一图块 I → 4 倍空间下采样的 VQ-VAE → 64 × 64 潜变量 → 加噪。
③ 条件去噪U-Net 接收带噪潜变量、时间步 t 和经 cross-attention 注入的条件 y，学习去噪。

SSL 编码器与 VQ-VAE 不要混淆。前者负责“这块组织是什么样”的条件描述；后者负责把图像压到扩散所用的低分辨率空间。官方单图块 notebook 的采样形状为 [3, 64, 64]，解码后得到 256 × 256 RGB 图像。

论文 §4.2 具体使用 4× 下采样 VQ-VAE，并微调 ImageNet 预训练 U-Net。训练样本是图块与它的 SSL 特征配对，不是人工文本—图像对。推理时，固定条件而改变噪声，就可以生成语义接近但像素不同的组织变体；这不是对参考图像的逐像素复原。

03

大图推理：每一步都协商，而不是最后才拼接

以官方 1024 × 1024 示例为例：参考图分为 4 × 4 个 256 × 256 图块，提取 16 个条件向量，并保留空间排列。然后初始化一张形状为 [1, 3, 256, 256] 的大噪声潜变量画布。它对应最终 1024 × 1024 图像，但网络每次仍处理 64 × 64 的潜窗口。

  1. 取重叠窗口：从同一张当前画布中截取多个局部窗口。重叠意味着同一位置会被多个窗口看到。
  2. 为窗口准备条件：窗口可能跨越原图块边界，所以条件不能只生硬地选左边或右边。论文对特征网格做空间插值；代码使用四邻域、先横向再纵向的球面插值 SLERP。
  3. 各窗口做一步去噪：使用同一个训练好的图块模型，各自结合所在位置的条件给出局部预测。
  4. 重叠位置求共识：把预测放回原坐标，对重复覆盖的位置取平均，得到下一步共享画布。所有窗口在下一时间步重新从这张画布取输入。
  5. 循环后解码：官方实现再次滑窗解码，并用中心权重更高的高斯核融合像素输出，减轻解码边缘效应。

核心区别：不是先各自画完再模糊边缘，而是在整个生成过程中共享状态。语义网格负责布局，逐步重叠融合负责局部一致性，两者缺一不可。MultiDiffusion 是论文采用的已有框架，并非本文首次提出；本文把 SSL 条件与这种大图生成方式结合起来。

Jₜ₋₁ = argminⱼ Σᵥ ‖Cropᵥ(J) − Φ(Cropᵥ(Jₜ) | λᵥ(Z))‖²
逐位置的解：Jₜ₋₁(p) = 覆盖位置 p 的窗口更新之和 ÷ 覆盖次数

对应论文 Eq.(5)–(6) 的简写：Z 是 SSL 条件网格，λ 是条件插值，Φ 是一步局部扩散更新，v 是窗口索引。这里的最小二乘有平均形式的闭式解，不是每步额外训练一个优化器。实际代码先平均各窗口的干净潜变量估计 x₀，再进行全局采样更新。

“全局结构”从哪来？主要来自条件网格的空间布局，不是一个在所有细胞之间做全局注意力的巨型网络。特征描述与局部重叠一致性，也不构成对全局组织拓扑或诊断正确性的严格保证。
04

亲手看看：重叠更多，为什么更贵？

固定输出 1024 × 1024，潜画布 256 × 256，窗口 64 × 64。只改变潜空间滑动步幅；候选值都能完整覆盖画布。

方格代表窗口数量，最多绘制 169 格，更多窗口用文字计数。这是几何计算演示，不运行神经网络，不显示伪造的生成结果或质量曲线。

默认步幅 16 对应像素空间 64；每轴 (256−64)/16+1 = 13 个位置，总共 169 个窗口。代码将有条件与无条件输入拼在一个 batch 中，因此一次 U-Net 调用会处理 338 个窗口输入。50 个时间步累计是 16,900 个窗口输入样本，不是 16,900 次独立 Python 网络调用。

结论是模型参数量不随输出尺寸增大，不等于显存和总计算量不增长。尤其公开示例一次堆叠全部窗口，不能未经验证就宣称能在 24 GB 卡上直接运行任意尺寸。大画布、窗口 batch 和采样步数都会影响资源消耗；具体显存和耗时仍需实测。

05

没有参考图像时，文本怎样进来？

基础路线需要一个条件网格，但网格不一定非得从参考图像提取。论文 §3.3 增加辅助模型 p(Z | c)，先把高层条件 c（例如文本）变成空间排列的 SSL 特征，再复用原来的图块扩散模型生成大图。

文本 → 辅助条件生成模型 → SSL 特征网格 → 大图扩散。这与把一句话直接送进当前 BRCA notebook 不同。论文借助 Quilt、CLIP、BLIP 等预训练多模态模型构造训练条件；对基因组等模态的提及是可扩展方向，不应当作所有模态均已有完整实验与发布模型。

目前核对到的官方 README 明确提供图块和大图两个 notebook，以及四组图像生成模型。不能据此声称文本辅助模型及其完整推理资源同样已公开可跑。

能回答这三题，就抓住了路线

1. 为什么只用一个“乳腺癌”标签，不够生成大图？

它不能区分各位置的局部组织语义。SSL 向量提供图块级内容差异，空间排列提供布局。

2. 为什么不把 16 个图块独立生成后拼起来？

独立采样没有共享状态；本文在每个时间步融合重叠预测，再让窗口读取同一张更新后的画布，因此协调发生在生成过程中，而不只是输出阶段。

3. 已有 SSL 特征是否意味着可以无条件、无限尺寸、零成本生成？

都不是。仍依赖有意义的条件网格；公开函数固定 1024²；尺寸和窗口数增加会提高计算与内存开销。语义相似也不是病理真实性保证。
