PAPER STUDY / GENERATIVE MRI

让第二个对比度
替测量说话。

欠采样的 MRI 重建是病态问题：许多张图像都能解释同一组测量。无条件生成先验只见过“MRI 一般长什么样”，没见过这位患者长什么样，于是它在零空间里补上人群常见的结构——看起来合理，却可能是错的。MPFlow 的赌注是：这次扫描里本来就有的另一路对比度（T1），可以在推理时把零空间里的内容锚定住，而完全不动先验的权重。

01

幻觉有两种，病根不一样

论文一开头就做了区分，这个区分是整篇方法的骨架。内在幻觉（intrinsic）违反测量一致性——重建出来的图，正演回去对不上真实采到的数据。外在幻觉（extrinsic）更麻烦：它和测量完全一致，但仍然不是真相。

为什么会有后者？因为欠采样把前向算子 F 变成了严重病态的映射。零空间里那一整族图像，正演之后给出同样的 y。测量只说“这些解都合格”，不说“哪一个是对的”。生成先验这时候顶上来，用训练集里的常见结构把空位填满——填得越像真的，越难被发现。论文 §1 与 §2.1

最容易读错的一点。既然外在幻觉与测量一致，那么“把测量误差压到更小”并不能把它消掉。论文正是拿这一点当切口：DC 误差小 ≠ 重建对。
02

辅助模态补的是零空间

把问题和盘托出：测量是 y，目标模态图像是 x，另有一张同一患者的辅助模态 xaux（论文里是配准好的全采样 T1）。退化模型写成一个前向算子加噪声。

论文 Eq.1 / 退化模型
y=F(xtrue)+η,η∼N(0,σ2I)y=F(x_{\text{true}})+\eta,\qquad \eta\sim\mathcal{N}(0,\sigma^2 I)y=F(xtrue​)+η,η∼N(0,σ2I)
y = F(x_true) + eta, eta ~ N(0, sigma^2 I)
F
前向算子。论文在两套任务上用它：HCP 是 4× 空间下采样（超分），BraTS 是 8× k 空间欠采样。
xtrue
目标高质量扫描，也就是重建想恢复的东西。

论文的论证很克制，只用一步信息论：无条件后验 p(x|y) 在病态情况下很宽，这就是外在幻觉的来源。加上辅助模态后，后验变成 p(x|y,xaux) ∝ p(y|x)·p(x|xaux)，剩余不确定性由条件熵给出，比原来少了辅助模态带来的那部分互信息。

论文 Eq.2 / 不确定性为什么会下降
H(x∣y,xaux)=H(x∣y)−I(x;xaux∣y)H(x\mid y,x_{\text{aux}})=H(x\mid y)-I(x;x_{\text{aux}}\mid y)H(x∣y,xaux​)=H(x∣y)−I(x;xaux​∣y)
H(x | y, x_aux) = H(x | y) - I(x ; x_aux | y)
配准后的不同 MRI 对比度共享同一套解剖结构，但信息并不完全重合，所以右边的条件互信息大于零，左端的熵就严格小于只给测量时的熵。

注意这是一个“在假设下成立”的推导，不是关于任意临床数据的定理：条件写死在 registered modalities encode the same anatomy。配准误差有多大、假设破裂时会怎样，论文没有做压力测试。

03

整流流：为什么 20% 的步数够用

先验不是扩散模型，是整流流（rectified flow）。它把“从噪声到图像”写成一条常微分方程的轨迹，网络学的是这条轨迹上的速度场。

论文 Eq.3–4 / 直线插值与速度场
dxtdt=vθ(xt,t),xt=(1−t)z+t x1,v(xt,t)=x1−z\frac{dx_t}{dt}=v_\theta(x_t,t),\qquad x_t=(1-t)z+t\,x_1,\qquad v(x_t,t)=x_1-zdtdxt​​=vθ​(xt​,t),xt​=(1−t)z+tx1​,v(xt​,t)=x1​−z
dx_t/dt = v_theta(x_t, t), x_t = (1-t) z + t x_1, v(x_t, t) = x_1 - z
噪声 z 在 t=0，数据 x₁ 在 t=1，中间的每一站都是两者的线性插值。插值走直线，所以“速度”就等于终点减起点，和时间无关。这正是它相对扩散模型能大步走的几何原因。
论文 Eq.5 / 训练目标与洁净估计
LFM=Et,z,x1∥vθ(xt,t)−(x1−z)∥22,x^1∣t=xt−(1−t) vθ(xt,t)\mathcal{L}_{FM}=\mathbb{E}_{t,z,x_1}\big\|v_\theta(x_t,t)-(x_1-z)\big\|_2^2,\qquad \hat{x}_{1|t}=x_t-(1-t)\,v_\theta(x_t,t)LFM​=Et,z,x1​​​vθ​(xt​,t)−(x1​−z)​22​,x^1∣t​=xt​−(1−t)vθ​(xt​,t)
L_FM = E || v_theta(x_t,t) - (x1 - z) ||^2 , xhat_{1|t} = x_t - (1-t) v_theta(x_t,t)
后半段的 x̂1|t 是整篇方法的关键中间量：在任意时刻 t，把当前状态沿学到的速度场投影回干净图像。采样时的两条梯度（下一节）都作用在它身上，而不是作用在噪声状态 xt 上。这一点和 DDS 同源——都把洁净估计当作握手变量。

INTERACTIVE / 几何示意
直线轨迹：折线偏离直线的最大距离0.000
弯曲轨迹：折线偏离曲线的最大距离0.000

纯几何示意：把 ODE 求解换成折线段，比较两种轨迹的离散误差随步数的变化。整流流走直线，折线与直线完全重合，所以这里的“偏离”恒为零；弯曲轨迹在步子大时明显偏离。它解释了论文“步数可大幅减少”的几何直觉，不是论文的实验数值——论文用的是 T=100 与 T=500 在 HCP/BraTS 上的实测对比（见 06 节）。

04

PAMRI：把两种对比度拉到同一个潜空间

要让辅助模态在采样时发号施令，先得有个东西能判断“当前重建和 T1 是不是同一套解剖”。直接比像素行不通：FLAIR 上肿瘤很亮，T1 上它可能几乎是等信号；反过来，T1 的灰白质对比在 T2 上又换了个样子。像素级的相似度度量在这里会系统性撒谎。

PAMRI 的答案是学一个共享潜空间：目标模态一个编码器 φ，辅助模态一个编码器 ψ（论文用 ResNet18，为了推理时开销小），各自把 32×32 的 patch 压成归一化嵌入 ui、wi，然后在潜空间里拉近配对 patch。论文 §2.4

论文 Eq.6 / 带自适应温度的对比损失
LNCE=12B∑i=1B(ℓ(ui,wi)+ℓ(wi,ui))ℓ(ei,ej)=−log⁡exp⁡(ei⊤ej/τi,j)ZiZi=∑k=1Bexp⁡ ⁣(ei⊤uk/τi,k)+∑k=1Bexp⁡ ⁣(ei⊤wk/τi,k)−exp⁡ ⁣(ei⊤ei/τi,i)\begin{aligned}\mathcal{L}_{NCE}&=\frac{1}{2B}\sum_{i=1}^{B}\big(\ell(u_i,w_i)+\ell(w_i,u_i)\big)\\ \ell(e_i,e_j)&=-\log\frac{\exp(e_i^{\top}e_j/\tau_{i,j})}{Z_i}\\ Z_i&=\sum_{k=1}^{B}\exp\!\big(e_i^{\top}u_k/\tau_{i,k}\big)+\sum_{k=1}^{B}\exp\!\big(e_i^{\top}w_k/\tau_{i,k}\big)\\ &\qquad-\exp\!\big(e_i^{\top}e_i/\tau_{i,i}\big)\end{aligned}LNCE​ℓ(ei​,ej​)Zi​​=2B1​i=1∑B​(ℓ(ui​,wi​)+ℓ(wi​,ui​))=−logZi​exp(ei⊤​ej​/τi,j​)​=k=1∑B​exp(ei⊤​uk​/τi,k​)+k=1∑B​exp(ei⊤​wk​/τi,k​)−exp(ei⊤​ei​/τi,i​)​

分母里同时出现 u 与 w，意思是负样本既有跨模态的，也有同模态的：不仅“别的患者”是负样本，同一患者的其他 patch 也是。整个损失是 1/(2B) Σ (ℓ(ui,wi) + ℓ(wi,ui)) 的对称形式。

读公式时的坑：论文里 z 同时被用作初始噪声（Eq.4）和对比特征（Eq.6 的 zi ∈ {ui, wi}），审稿人 #3 专门指出过这一点，作者承诺改稿时区分。
论文 §2.4 / 温度由两模态的互信息决定
τi,j=τmin⁡+(τmax⁡−τmin⁡)(1−NMI(pi,pj))\tau_{i,j}=\tau_{\min}+(\tau_{\max}-\tau_{\min})\big(1-\mathrm{NMI}(p_i,p_j)\big)τi,j​=τmin​+(τmax​−τmin​)(1−NMI(pi​,pj​))
tau_ij = tau_min + (tau_max - tau_min) * (1 - NMI(p_i, p_j))
这一行是 PAMRI 最有想法的地方：互信息不用来直接对齐像素，而是用来调对比损失的温度。两个 patch 本来就不像（比如被增强扭曲过的配对），NMI 低，温度升上去，把“拉近”的力度放松，从而保住模态特有的结构；反过来，NMI 高的配对就被更紧地拉到一起。

05

采样时加两条梯度

到了推理这一步，方法其实很朴素：不改权重，只改轨迹。每个时间步先让速度场给出下一步，再在洁净估计上叠加两条修正梯度——一条朝测量，一条朝辅助模态的潜空间特征。

原表数字说明了什么

先看图像质量主表。两套任务都在，T 是采样总步数，p 值是相对每个指标的第二名算的。

TABLE 1 / 主结果（论文原表数值）

数值由论文 Table 1 逐格转录。不同 T 的方法并排比较时请留神预算差异：DIP 是 3K 步，DPS / DynamicDPS 是 .1K 与 .5K，MPFlow 是 .1K 与 .5K。

08

你应该从它带走什么

最可迁移的思想不是“用了 T1”，而是把额外信息放进采样时的梯度，而不是放进权重。先验保持通用、不重训；要引入的偏置以一条可解释的梯度项进入轨迹。这个结构可以接任何无条件的生成先验，也可以接任意一种“怎么判断两张图是同一套解剖”的特征度量。

和站内路线对照着看更清楚：DDS 用便宜的一致性求解替换昂贵的网络梯度，关注的是每一步怎么算；MPFlow 关心的是每一步朝哪偏，并且为此专门训了一个跨模态特征空间。UP MRI、FLEX-MRI 走的是条件流匹配与随机探索，方向又不同。

一个好的后续问题：
当辅助模态本身不完美时，
这条引导梯度还该不该信？
ONE SENTENCE TO CARRY AWAY梯度，不是权重

把额外信息放进采样时的梯度，而不是放进权重：先验保持通用、不重训，要引入的偏置以一条可解释的梯度项进入轨迹。这个结构能接任何无条件生成先验，也能换掉「怎么判断两张图是同一套解剖」的特征度量——MPFlow 只是选了 PAMRI。

它的代价是推理时多做一次反向传播，以及需要一个已经配准好的辅助模态。这两条前提都没有被压测过。

论文没有回答这个问题的任何一个版本：两套数据都是预配准的，辅助模态都是全采样高质 T1，也没有考虑只有一个辅助模态之外的扩展。以下三个切口都是本站提出的研究问题，尚未做新颖性检索，请当作待验证的选题建议，而不是已验证的创新。

THREE PROPOSED CUTS

  • 把配准误差变成可调变量。对辅助模态施加可控的平移 / 旋转 / 层厚失配，看 SHAFE 与 Dice 如何随失配增大而退化，再试一个把失配估计写进引导权重的版本。这条直接命中审稿分歧中最硬的一条——两套数据都是预配准的，方法从未见过错位。
  • 真正做出自适应温度并消融。论文 Eq.6 的 τi,j 在公开代码里找不到对应实现。先复现固定温度，再实现 NMI 自适应，比较跨模态相似度分布是否更可分、下游 SHAFE 是否更低。便宜、可证伪、有明确对照。
  • 把两条梯度的预算摊销做成一件事。DC 与 PAMRI 各管一类幻觉，但论文没有回答「给定总预算，怎么在两者之间分配」。固定采样步数，扫 αt 与 λP 的网格，记录测量残差、SHAFE、Dice 与总耗时，专门去找「残差下降但 SHAFE 变差」的区域。

以下四件事决定你能不能真的把它跑起来——它们都不是论文的问题，而是拿到代码前必须知道的现实条件。

  • 数据要自己凑。HCP 的 T1/T2 配对与 BraTS 官方验证集都需自行获取；代码里的数据路径是作者集群的绝对路径，不能直接跑。
  • 没有现成权重。仓库不含任何 checkpoint，整流流先验与 PAMRI 编码器都要从头训练；整流流与扩散模型各 100k 迭代。
  • 评测链路要补两件东西。Dice 需要额外训一个 Swin-UNet 分割器；SHAFE 依赖预训练视觉编码器（论文用 DINO）与指数加权聚合。
  • 先确认版本。公开快照与投稿版本存在三处不一致（见 07 节），先向作者确认论文对应的提交，别默认 master 就是论文实现。

最后一句提醒：这篇的位置是一次推理时的条件化，不是新的重建网络。它的价值取决于你是否接受“辅助模态已在手且配准良好”这个前提。接受，它就很实用；不接受，整篇的技术收益要打一个折扣。审稿人正好分裂在这一条上。

09

合上论文前，检查自己真的懂了没有

01 / 为什么数据一致性做得好，还是可能有幻觉？

因为有两类幻觉。外在幻觉存在于测量零空间里：重建图像正演回去与 y 一致，但解剖结构不是真的。DC 只约束测量空间，对零空间里的内容没有约束力，所以 DC 误差小与重建正确是两件事。论文正是用这一点引出辅助模态。

02 / MPFlow 重训了生成先验吗？

没有。整流流先验保持不变，辅助模态只在推理时通过梯度项进入。PAMRI 需要事先在一份配对、配准的多模态数据上预训练，且作者确认它与生成先验用同一训练划分、与测试集不重叠。所以“零样本”指的是不做任务特定的重训，不等于不需要任何预训练。

03 / PAMRI 为什么不用互信息直接做像素对齐？

因为跨模态的强度对应不可靠：同一个肿瘤在 FLAIR 上很亮、在 T1 上可能近乎等信号，像素级相似度会系统性误判。PAMRI 把 NMI 降到温度上——用它调对比损失的松紧，而把真正的对齐放在学习到的潜空间里做。

04 / 论文报的 T=100 成本，就是完整的推理成本吗？

不是。初始噪声优化要并行跑 S=8 个候选各 tnoise=0.2T 步，再跑剩下的 0.8T，等效约 240 NFE，是标称 T=100 的 2.4 倍。这个记账由审稿人 #3 指出，作者在 rebuttal 里用 T=240 重跑基线作为回应，但那组实验属于 rebuttal 补做，按指南不计入投稿版本的证据。

05 / 引导项里那个 LP 到底在比什么？

比的是两张图在 PAMRI 潜空间里的 patch 特征。x̂ 和 xaux 各自按 32×32 切成不重叠 patch（去掉脑掩码之外的块），分别过 φ 与 ψ，逐 patch 求嵌入均方误差。所以它是“同一套解剖”的语义度量，不是强度度量。

06 / 这篇论文最容易被引用的结论是哪一条？

不是某个具体指标，而是“辅助模态可以在推理时重塑后验几何，而不需要更新无条件先验”。这句话出现在结论里，也几乎是它在方法层面的全部主张。具体数字（20% 步数、Dice +15%、SHAFE −26%）都带明确的前提条件，跨设定外推时要重新验证。
