## 1. 为什么读这篇

把预先给定影像的问答改成主动调查：Agent 自己选择患者访视、器官、MRI 序列、切片与专用工具。适合连接本站医学 Agent 与 MRI 两条路线。

## 2. 三分钟摘要

CASE 将角色化取证工具与视觉语言策略模型结合，通过轨迹监督微调、Agent 强化学习、自蒸馏及评分反馈学习纵向医学调查。基准来自 UK Biobank，问题关联同一患者基线与随访影像。

## 3. 它到底怎么做

1. 接收临床问题与患者环境入口。
2. 选择访视、影像与专用工具获取证据。
3. 依据返回内容继续调查与比较。
4. 综合纵向证据形成回答。

## 4. 实验与阅读检查

作者报告 4,739 名参与者、50,401 个问题及 14,734 条监督轨迹。

以下是本站建议的精读检查项：

- 按患者划分数据，是否隔离同一人的多次访视与相似问题？
- 工具、交互预算与模型输入一致时，后训练分别带来什么收益？
- 查 SFT、RL 与自蒸馏消融，区分策略学习和答案记忆。

## 5. 与现有路线的联系

与 MedAgent-Pro 的证据反思对读：重点比较证据如何取得，以及调查动作如何学习。
