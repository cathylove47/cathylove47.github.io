## 1. 为什么读这篇

EHRAgent 展示如何用代码访问 EHR，本篇进一步问：当查询跨表、跨时间和跨人群时，Agent 是否能稳定得到正确结果？

## 2. 三分钟摘要

EHR-Complex 基于 MIMIC-IV 构建交互式临床数据库任务，Agent 在沙箱中执行 SQL 或 Python。任务覆盖患者级与人群级分析，强调纵向聚合与组合推理。

## 3. 它到底怎么做

1. 接收临床问题与数据库工具。
2. 查找表结构及医学编码。
3. 执行查询或代码并利用反馈修正。
4. 输出结果并评价重复运行一致性。

## 4. 实验与阅读检查

摘要报告约 52K 任务、31 张表，最佳模型 exact-match 为 62.3%；另分析重复运行一致性与失败轨迹。

以下是本站建议的精读检查项：

- 对照患者级和人群级结果，检查多表聚合与时间条件。
- 区分 Pass@k 的至少一次成功与 Pass^k 的连续成功定义。
- 沿失败轨迹定位 SQL 逻辑、医学编码查找和语义理解错误。

## 5. 与现有路线的联系
