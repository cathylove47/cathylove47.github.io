# DC-CNN

## 三分钟摘要与推荐理由

DC-CNN 把“CNN 去伪影”和“数据一致性（data consistency）”交替堆叠，是理解深度 MRI 重建最直观的起点。它的价值不在今天仍是最强，而在于把纯图像网络拉回到测量物理中。

## 问题与研究位置

欠采样会在图像域产生结构化混叠。单次 CNN 可能修复外观却改动已测得频率；级联结构在每个阶段后把观测 k-space 重新写回，从而约束网络。

## 核心方法和数据流

零填充图像 → CNN 残差去伪影 → FFT → 已采样位置数据一致性更新 → IFFT；重复多个 cascade。阅读时画出张量从图像域到频域再返回的环路。

## 关键实验、数据集与指标

论文关注笛卡尔欠采样的心脏 MRI，并比较不同加速率。建议复现时同时报告 PSNR/SSIM 与误差图，避免只看平均指标。

## 官方代码仓库审计

`js3611/deep-mri-reconstruction` 提供 2D、动态重建和 CRNN 示例及预训练模型。早期实现含 Theano/Lasagne，PyTorch 部分也依赖旧版本，因此更适合读思想和跑 demo，不适合作为现代工程底座。

## 资源与数据准备

demo 成本低；完整复现的主要风险是旧环境。建议用容器或只复刻数据一致性层到现代 PyTorch，不要把环境迁移与方法验证混在一次实验里。

## 建议复现路径

1. 用仓库预训练模型跑一个 demo。
2. 单独实现 hard data consistency，并做单元测试。
3. 在 fastMRI 小子集复刻 3–5 个 cascade。
4. 比较共享/不共享级联参数。

## 建议代码阅读顺序

`cascadenet_pytorch` → `main_2d.py` → `main_crnn.py` → `utils`。优先定位 Fourier 与 data-consistency 操作。

## 可迁移思想与博士切入点

“学习先验 + 显式测量约束”适用于 CT、PET、显微成像等逆问题。研究机会包括软/硬一致性的可靠性、噪声模型失配和不确定性传播。

## 局限与复现风险

旧框架、较小数据和回顾性采样限制了结论外推；级联深度增加后也缺乏明确优化解释。

## 与前后论文的关联

fastMRI 提供统一数据；MoDL 将级联解释为优化展开，并用共轭梯度处理更一般的前向模型。
