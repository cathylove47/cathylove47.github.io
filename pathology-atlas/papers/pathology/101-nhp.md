## 原文摘要

> Histopathologic analysis of stained tissue remains central to biomedical research and clinical care. Virtual staining (VS) offers a promising alternative, with potential to reduce costs and streamline workflows, yet hallucinations pose serious risks to clinical reliability. Here, we formalize the problem of hallucination detection in VS and propose a scalable post-hoc method: Neural Hallucination Precursor (NHP), which leverages the generator's latent space to preemptively flag hallucinations. Extensive experiments across diverse VS tasks show NHP is both effective and robust. Critically, we also find that models with fewer hallucinations do not necessarily offer better detectability, exposing a gap in current VS evaluation and underscoring the need for hallucination detection benchmarks.

*来源：arXiv:2411.15060v2 摘要，逐字保留。*

## 中文摘要

> 染色组织的组织病理学分析始终是生物医学研究与临床诊疗的核心。虚拟染色（VS）提供了一个有前景的替代方案，有望降低成本、简化流程，但幻觉对临床可靠性构成严重风险。本文把 VS 中的幻觉检测问题形式化，并提出一个可扩展的事后方法：神经幻觉前兆（NHP），它利用生成器的隐空间来提前标记幻觉。跨多种 VS 任务的广泛实验表明 NHP 既有效又稳健。关键在于，我们还发现幻觉更少的模型并不必然带来更好的可检测性，这暴露出当前 VS 评测中的一个缺口，也说明建立幻觉检测基准的必要性。

## 0. 三分钟摘要

**一句话**：幻觉检测不必看输出像不像——看**生成器自己在生成这一块时的中间特征**偏不偏；偏了就是它"心里没底"，事后挂个 KNN 探针就能打分。

**问题**：虚拟染色能省染色、省时间，但会编造组织学结构（细胞核丢失、被别的结构顶替）。已有两条检测路线都是从 GAN 的判别器/循环一致性借来的 OOD/异常检测思路，而作者的论点是：**幻觉既不等于 OOD，也不等于离群**——分布内的样本照样会因为欠定（underspecification）和数据歧义而幻觉，分布外的样本也可能被生成得很好。检测必须对准"这次预测到底准不准"，而不是"这个输入新不新"。

**insight**：生成器在合成错误结构时，中间层特征会偏离"它见过的、且生成正确"的特征区域。所以只要有一份带真值的校准集，把其中**生成质量差的那部分剪掉**，剩下的特征就构成一个"安全记忆库"；测试时算测试特征到库中第 $k$ 近邻的归一化距离，再乘上特征范数项，就是一个标量可信度。四个超参（层、剪枝比例、$k$、范数指数）逐任务网格搜索。

**它到底做到了什么**：
- 14 个 VS 配置上平均 HRP **52.4%**，是表里最好的；深集成（10 成员）42.4%，GAN 判别器类方法（ALOCC/ALAD/f-AnoGAN）为 **−0.7 / −3.8 / 3.3**，基本等于瞎猜或更差。
- 换幻觉度量也站得住：用 MIRrel（细胞强度比）和病理基础模型（Prov-GigaPath、自训 DINO ViT）的结构误差当 $\mathcal{Q}$，NHP 仍是第一或第二。
- 在加噪/模糊/压缩的 OOD 集和 PGD 对抗集上仍有平均 HRP 49.6% / 44.9%，相对校准集的落差只有 3.99% / 8.7%。
- 一位病理医生盲评 22 组，NHP 高分块与低分块的"更像幻觉"判断一致度均值 **0.41**（+1 一致 / 0 持平 / −1 相反）——中等一致，不算强。
- **最重要的负面发现**：同一任务里 20 个模型的"平均水平 AP"与"可检测性 HRP"经常**负相关**。幻觉更少的模型，不一定更好检测。

## 1. 问题与核心判断

### 1.1 幻觉怎么定义

定义极简，而且**完全操作化**：预测 $G(\mathbf{s})$ 与对应真值 $\mathbf{t}$ 的全参考（full-reference, FR）相似度 $\mathcal{Q}$ 越低，幻觉越重（§2.1）。默认 $\mathcal{Q}\in\{\text{PSNR}, \text{MS-SSIM}, \text{LPIPS}\}$（LPIPS 取负以统一方向）。

三个后果值得记住：

1. **必须有配对或"非严格配对"数据**才能评测。VS 领域常用相邻切片配准后的"inconsistent pair"，作者接受它作为近似真值。
2. **"幻觉"在这里是个连续量，不是事件**。没有"这块编造了一个核"这种标注，只有"这张 patch 的 SSIM 掉了"。所以后文说"幻觉更少"，严格说是"平均 $\mathcal{Q}$ 更高"。
3. 必须用 FR 指标而非无参考指标，理由是要抓**高真实感幻觉**（Fig. 1-b iii）：输出完全落在目标域流形内、但和真值不符——无参考指标天生看不见这种。

### 1.2 为什么不是 OOD / 离群检测（§2.4）

作者花了一整节反驳，这是全文的概念核心：

- **OOD 不蕴含失败**：他们的 VS 模型在模拟 OOD 下 $\mathcal{Q}$ 只轻微下降（Fig. 2-b-c），若把所有 OOD 都拒掉，误报率会让系统不可用。
- **幻觉不蕴含 OOD**：分布内样本也会因数据歧义（一对多映射）和欠定（Rashomon 集里无数个同样满足 ERM 的模型）而幻觉。
- **离群也不等价**：Fig. 2-d 的 UMAP 显示"离群但 $\mathcal{Q}$ 高"和"不离群但 $\mathcal{Q}$ 低"都存在。
- 语义新颖（semantic novelty）在 VS 里反而不该拒：分类任务必须拒新类，VS 可以正确合成没见过的组织类型。

一句话：**OOD 对幻觉既非必要也非充分**。

### 1.3 幻觉的三个来源（§2.2，Fig. 2 用定向消融验证）

| 阶段 | 机制 | 论文里的消融 |
|---|---|---|
| 数据采集 | 测量噪声、源模态信息不足 → 问题本身不适定（aleatoric） | 给 SRS 加噪；把光谱通道减半 |
| 模型训练 | 收敛不足；欠定导致解不唯一（epistemic） | 提前停止训练；Pix2PixHD 换 CycleGAN |
| 模型推理 | 分布漂移；对抗扰动（epistemic） | 测试样本 OOD 化；PGD 攻击 |

这张分类表是本文最可复用的部分：它把"幻觉"从一句抱怨拆成可分别消融的工程原因。

## 2. 术语（先用白话）

| 术语 | 白话 |
|---|---|
| VS（virtual staining） | 用一张已拍的图（无标记、SRS、HO342、H&E）算出一张没拍的染色图 |
| 幻觉 | 本文定义为"输出与真值的 FR 相似度低"，是个连续分数，不是事件标注 |
| $\mathcal{Q}$ | 全参考相似度指标（PSNR / MS-SSIM / LPIPS / MIRrel / 病理特征结构误差） |
| AP（average performance） | 测试集上 $\mathcal{Q}$ 的均值，衡量"平均有多准 / 幻觉有多少" |
| HRP | 把监控器的排序能力和随机、oracle 比，归一化到 0–1，衡量"可检测性" |
| 弃权测试（abstention） | 按分数拒掉最不可信的一部分样本，看留下的那部分 $\mathcal{Q}$ 有没有变好 |
| 特征记忆库 | 校准集里"质量过关"样本的中间层特征集合，KNN 的参照物 |
| FN（feature norm） | 特征向量的 $\ell_2$ 长度，本文把它当作额外的置信线索 |
| 自调参（self-tuning） | 校准集直接从训练集抽样，超参在它的留出部分上网格搜索 |
| 特征坍缩（feature collapse） | 更强的模型把隐空间压得更紧，异常特征和正常特征挤在一起 |

## 3. 核心方法与数据流

```text
离线：校准集 D_c（含真值 t）
  ① 用生成器 G 跑一遍，算 Q(G(s_c), t_c)
  ② 剪枝：只保留在所有 Q 上都高于 (1−q) 分位的样本 → D_c^q（q=0.75 意味着只留最好的 25%）
  ③ 取第 l 层特征，全局平均池化 → z_c^l，堆成记忆库 Z_c^q ∈ R^{N×D}
  ④ 在 D_c 的留出 25% 上网格搜索 (l, q, k, γ)，目标是 HRP 最大；重复 10 次不同划分

在线（单个 patch）：
  测试源图 s → G 的第 l 层特征 → 平均池化 → z^l
  → 归一化后与库中每个 z_c 算 ℓ2 距离 → 取第 k 小 = r_(k)
  → f(s) = − r_(k) · ‖z^l‖₂^γ
  → 分数低 = 可疑，交给人工或拒收
```

### 3.1 打分函数（Eq. 5）

$$f_{\text{NHP}}(\mathbf{s})=-\,r_{(k)}\cdot\lVert \mathbf{z}^{l}\rVert_{2}^{\gamma}$$

其中 $r_{(k)}$ 是归一化查询特征 $\mathbf{z}^l/\lVert\mathbf{z}^l\rVert_2$ 与库中归一化特征的**第 $k$ 小** $\ell_2$ 距离，$\gamma$ 用来放大（$\gamma\gg0$）、消去（$\gamma=0$）或反转（$\gamma\ll0$）范数项；负号保证"距离大 → 可信度低"。距离和范数各自标准化后再相乘。

### 3.2 相对朴素 KNN 的四处改动（§3.2）

作者自己列得很清楚，这张对照表就是"为什么不能直接套 OOD 方法"的清单：

| 朴素 KNN（OOD 检测） | NHP | 理由 |
|---|---|---|
| 固定倒数第二层 | 调 $l\in\{0,0.25,0.5,0.75,1\}$ | 幻觉不一定是语义级的，最优层未知 |
| 不剪枝（$q=0$） | 调 $q$，且剪掉**所有** $\mathcal{Q}$ 都差的样本 | 训练集里的"安全"样本本身可能就在幻觉，不剪就是把错的当基准 |
| 丢掉特征范数（$\gamma=0$） | 调 $\gamma$ | 分类任务里 ID 范数偏大是要解耦的干扰，I2IT 里范数是真信号 |
| 用拼图/对抗造伪 OOD 调参 | 自调参 | 训练集里本来就有幻觉，不需要人造伪 OOD |

### 3.3 评价指标 HRP（Eq. 1–2）

先做弃权扫描：设阈值 $\lambda_p$ 使保留集 $\{f\ge\lambda_p\}$ 占 $1-p$，算保留集上的平均 $\mathcal{Q}$，对 $p\in[0,1]$ 积分得 $\mathrm{AUC}_f$。再用两个参照归一化：

$$\mathrm{HRP}=\frac{\mathrm{AUC}_f-\mathrm{AUC}_{\text{random}}}{\mathrm{AUC}_{\text{oracle}}-\mathrm{AUC}_{\text{random}}}$$

- $\mathrm{AUC}_{\text{random}}$：随机排序，等价于全体平均 $\mathcal{Q}$；
- $\mathrm{AUC}_{\text{oracle}}$：直接拿真实 $\mathcal{Q}$ 当分数排序，是上界。

所以 HRP 的含义是"**监控器的排序能力，相对真实 $\mathcal{Q}$ 排序能力的百分比**"。它天然抵消了模型本身好坏的影响——这正是后文能跨模型比较的前提，也是 §4.3 那个负相关能被看见的原因。

注意 HRP 达不到 100%：不同 $\mathcal{Q}$ 之间排序本身就不一致，作者报 Kendall's $\tau$ 在 0.4–0.5。

### 3.4 超参与规模（§4.1）

搜索空间：$l\in\{0,0.25,0.5,0.75,1\}$，$q\in\{0,0.25,0.5,0.75\}$，$k\in\{1,10,25,50,100,200\}$，$\gamma\in[-10,10]$ 步长 0.5。校准集从训练集分层抽样：SRS 全用，HO342 取 1%，MIST 取 10%，每任务约 3–7K 样本。每个模型跑 10 次、每次换 25% 的调参划分，共 1400 个 NHP。

### 3.5 复杂度（§3.3）

Faiss `IndexFlatL2`，$O(ND)$；$N\sim5$K、$D=64$ 时单 patch 亚毫秒，批处理约 1 ms / 100 patch，内存约 1.28 MB（float32），可进 L2/L3。相比扩散/集成方法（多成员训练或多前向），开销可忽略——这是它作为"可部署监控器"的主要卖点。

|---|---|---|

三点观察：

1. **GAN 判别器路线整体失效**。作者解释：ALOCC 只惩罚偏离目标分布，而高真实感幻觉恰好落在目标分布内，天生抓不到；且对判别器训练是否充分极度敏感。
2. **深集成 10 成员是唯一有竞争力的对手**，且在 SRS→H&E 的 VSGD 上赢了 NHP（47.5 vs 37.2）。作者给的解释是"模型们会一起幻觉"（共享归纳偏置 → 预测分歧小）。
3. 消融的方向一致但幅度不一：去掉剪枝掉 12.3，去掉范数掉 4.6，换线性组合掉 0.8。

### 4.2 超参能不能固定？（Table 2、Fig. 4b）

Fig. 4b 统计 1400 个 NHP 收敛到的超参：**只有 $q$ 一致**（普遍偏好激进剪枝 $q=0.75$）；$l$ 一般偏好倒数第二层，但 HO342 上浅层更好；$k$ 和 $\gamma$ 分布极散。

Table 2 直接验证"固定成最优值会怎样"：把 $l=1$、$k=1$、$\gamma=-1$ 分别硬编码，平均 HRP 从 52.4 掉到 49.9 / 51.4 / 48.6。所以作者坚持逐任务网格搜索是必要的——这也意味着**每换一个生成器就要重调一次**，部署成本被低估了一点（见 §7）。

Fig. 6a 三张散点是逐模型的"校准集 HRP vs 测试/OOD/对抗 HRP"，$R^2$ 分别为 0.77 / 0.69 / 0.45。

### 4.5 病理医生盲评

从 SRS→H&E 里按 NHP 分数取 top 10% 与 bottom 10%，质控后交给一位 board-certified 病理医生（J.C.）盲评"哪一对更像幻觉"。22 组，计分 +1 / 0 / −1，均值 **0.41**。作者把一部分分歧归因于"$\mathcal{Q}$ 本身抓不住病理医生的感知"，即瓶颈在度量而不在 NHP。

### 4.6 核心发现：幻觉更少 $\neq$ 更好检测

这是全文最值得单独拎出来的一段（§4.2 "Performance vs detectability"，Fig. 6b）。

**先把两个量分清楚**（这是理解该结论的前提，不是我的引申）：

- $\mathrm{AP}=\mathbb{E}_{(\mathbf{s},\mathbf{t})\in\mathcal{D}_{\text{test}}}[\mathcal{Q}(G(\mathbf{s}),\mathbf{t})]$：测试集上平均相似度。**AP 高 = 平均而言幻觉更少/更轻**，但它是**频率与严重度的混合量**，且被大量容易样本主导。
- $\mathrm{HRP}$：监控器把"差的样本排在前面"的能力，**与幻觉出现频率无关**。一个几乎不幻觉的模型，HRP 依然可以很低——只要它偶尔犯的错恰好是监控器看不出来的那种。

**实验怎么做的**：对每个 VS 任务，取 20 个模型（2 backbone × 10 seed），每个模型算 6 个数：AP 与 NHP-HRP 分别在 test / OOD / adversarial 三个集合上；对这 6 个数做全部 $\binom{6}{2}=15$ 对 Kendall 秩相关；每个 $\mathcal{Q}$（PSNR、SSIM、LPIPS）单独算（量纲不同不能混）；共 7 数据集 × 3 度量 = 21 张棋盘图，不显著的格子置灰。

**结果**：Fig. 6b 中 AP–HRP 的格子**大面积偏红**（红 = τ 接近 −1，蓝 = +1）。也就是说，在同一任务、同一 backbone 家族内，**平均质量越高的模型，其打分器与真实 $\mathcal{Q}$ 的排序一致性往往越差**。作者还指出，连 HRP 自己跨条件也不一致，例如 HO342→CD3 上 MS-SSIM 的 OOD-HRP 与对抗-HRP 就互相打架。

**边界（必须一起写）**：正文没有给出任何逐格 $\tau$ 的数值，只有配色；横轴是"模型"而不是"样本"；每格只有 20 个点，不少格子因 $P>0.05$ 被置灰。所以严谨的表述是"**秩相关普遍呈负向趋势**"，不是"存在强负相关"。表格化的 $\tau$ 与置信区间，论文没给。

**作者给的解释**：可能是**特征坍缩**。GAN 里"尾部的异常隐特征"会触发伪影合成；更强的模型把隐空间压得更紧、尾部被削掉，于是幻觉变少了，但**幻觉与正常特征在隐空间里也更难分开**，NHP 的动态范围被压扁。

**我的白话直觉（明确是解读，不是论文结论）**：这就像两个学生——一个错得多但错得离谱（一眼能挑出来），一个几乎不错、错的都是极细微的术语混淆（题目全对，你无从判断他哪里不确定）。检测器靠"偏离常态的程度"排序，而"更准"往往意味着"偏离更小、更均匀"，于是可排序性反而下降。换个角度：AP 由大量简单样本决定，HRP 只关心**尾部**；把尾部削掉的优化，正好把 HRP 赖以工作的信号一起削掉了。

**这条结论的真正杀伤力**：如果按常规做法"先把 VS 模型训得更好，再拿检测器去比 AUROC"，就会把"幻觉变少"误读成"检测变强"。跨模型比较检测器时，必须把模型自身错误率作为基线控制住。这一点与我在幻觉检测评测里踩过的坑是同一类陷阱（详见 §6 与 §7）。

## 6. 前后关联

- **被它点名批评的两条检测路线**：[AQuA](100-aqua.md)（Huang et al.，循环翻译定义 hallucination index）与 Ounissi et al.（用判别器监控 H&E→IHC 置信度）。作者的批评很具体：AQuA 依赖逆向映射模型、有迭代翻译延迟，且只用"训练是否充分"来划分好坏模型；判别器路线则混淆了"源图损坏"与"输出幻觉"。
- **同问题、不同路线的邻居**：[HARP](102-harp.md) 也是事后检测，但它走的是"扰动/一致性"而不是隐空间距离，两者可以直接在同一批 patch 上比。
- **评测协议上的亲缘**：[HalluGen](../diffusion/11-hallugen.md) 与本文都把"幻觉检测"从"图像质量评价"里拆出来，都发现感知指标（LPIPS 类）对幻觉几乎无效——HalluGen 报 LPIPS 检测 AUC 0.51/0.50，本文报 ALOCC/ALAD 类判别器 HRP 为负，结论方向一致：**"看起来真"和"对不对"是两回事**。
- **虚拟染色的不确定性侧**：[I2I-Stain-Zoo](86-reliable-histological-staining.md) 用集成分歧做软分诊并发现它与任务误差几乎不相关（Pearson −0.025）；本文的深集成 10 成员能到 42.4% HRP，比它好，但仍输给一个 KNN 探针。两篇合起来说明：**不确定性≠可检测性**，且贵的方案不一定赢。
- **病理扩散修复侧**：[RestorePath](49-restorepath.md)、[ArtiFusion](55-artifusion.md)、[SuperDiff](78-histo-diffusion.md)、[DiffusionQC](74-diffusionqc.md) 都只报感知指标或做质量回归；本文提供了一个"盲打分 + 弃权曲线"的评价壳子，可以套到它们的输出上（前提是有配对真值）。
- **方法零件**：KNN-OOD（Sun et al., ICML 2022）是直接母体；DUQ / 确定性不确定性那条线（Van Amersfoort 2020、Postels 2022）是它的理论邻居。

**与本人研究的关系**（我的判断，不是论文主张）：我关心的是扩散修复在细胞级"编造/抹除"的检测，且推理时看不到干净原图。NHP 的结构与这个设定吻合——推理只看源图，真值只在离线建库和评测时用。但有三处不能直接照搬：(1) 它的"幻觉"是 patch 级 FR 指标分数，不是细胞级事件，标签粒度差一个量级；(2) 它要求配对校准集，而修复任务的"真值"往往就是被退化的那张图本身，配对是天然的，这点反而比 VS 容易；(3) §4.6 那条负相关，正是我评测检测器时要防的坑：**跨生成器比 AUROC 时，必须扣掉"输出计数基线"**，否则模型越强、错误越少，检测分数看起来越差或越好都可能是假象。

## 7. 局限与可检验问题

**作者承认的**（§4.3）：

- 只是基线，距离函数与层选择都可以更讲究（图方法、流形学习、按层间相似度选层）。
- **目标图伪影偏差**：方法默认目标图是干净真值；真实切片里目标图自带伪影而源图没有时，$\mathcal{Q}$ 被压低，NHP 会把"好输出"误标成幻觉（Fig. 5c 的黄色圈就是一个被误报的 H&E 伪影）。
- 单一分数把所有幻觉来源混在一起，不能区分 aleatoric / epistemic，也就不能指导"该重扫、该补数据、还是该改模型"。
- 只做 patch 级，微转移、孤立肿瘤细胞这类"针尖"任务需要更细的空间归因。
- 验证规模小、单中心；更大更异构的数据上，校准集要跟着变大，近似 KNN（IVF/IVFPQ）可能必需。
- 检测与缓解不天然一致，需要"既少幻觉又好检测"的统一框架。

**我的看法（作者没写的）**：

1. **"幻觉"被定义成指标分数，导致循环风险**。$\mathcal{Q}$ 同时用于剪枝、调参、评测三处，等于用同一把尺子定义问题、训练检测器、再给它打分。作者用留出集和 10 次划分缓解，但没有做"换一个 $\mathcal{Q}$ 调参、用另一个 $\mathcal{Q}$ 评测"的交叉验证——Table 3 是"换度量重调重评"，不是"用 A 调、用 B 评"。这是可以立刻做的实验。
2. **HRP 的可比性有隐藏前提**。HRP 归一化掉了 AP，听起来公平；但 oracle 上界本身依赖 $\mathcal{Q}$ 的分布形状。两个模型 AP 差很多时，它们的 $\mathrm{AUC}_{\text{oracle}}$ 也不同，归一化后的 HRP 未必是同一把尺子。Fig. 6b 的负相关有一部分可能来自这个归一化，而非特征坍缩。作者只给了"speculate"。
3. **每模型重调参 = 每模型都要一份带真值的校准集**。这在实际部署里等价于"新医院、新扫描仪、新染色批次都要重新收集配对数据"，比论文强调的"低算力"成本高得多。$q=0.75$ 的激进剪枝还意味着校准集的有效样本只剩 1/4。
4. **没有和"简单基线"比**。比如直接用源图的原生统计量、或直接用生成器输出与其自身的低频一致性做一个无参考分数。GAN 判别器和深集成都被打败了，但"最笨的无参考分数"没出现。
5. **病理医生验证太薄**。22 组、一位医生、只做 top/bottom 10% 的极端对比（本来就最容易分），0.41 的均值说服力有限；没有报医生内一致性，也没有报在中间区间的表现。

**可检验的问题**：

- 在 MIST 上把 $\mathcal{Q}$ 交叉使用（用 SSIM 调参、用 MIRrel 评测），HRP 掉多少？这直接检验"$\mathcal{Q}$-agnostic"有多强。
- Fig. 6b 的负相关，用"输出$\mathcal{Q}$ 分箱后比较"或"控制 AP 的偏相关"重算，还剩多少？如果消失，说明是归一化假象；如果留存，特征坍缩的解释才站得住。
- 对扩散式 VS（PST-Diff 等）取"中间层"取哪一层？扩散模型没有 GAN 那样的编码器-解码器瓶颈，Eq. 4 的语义会变，方法能否平移未验证。
- 把 NHP 的分数做成**热图**（对 patch 内滑窗）而不是 patch 级标量，能否定位到细胞级？论文只给了 patch 级。
