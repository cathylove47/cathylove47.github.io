# 42｜Libra-MIL：用视觉与文本原型做少样本 WSI 分类

**论文**：Libra-MIL: Multimodal Prototypes Stereoscopic Infused with Task-specific Language Priors for Few-shot Whole Slide Image Classification，AAAI 2026  
**定位**：少样本 MIL、任务相关语言先验、跨模态最优传输  
**建议投入**：先用 CONCH 特征与仓库内 RCC prompt 跑通 1/4/16-shot；不要从原始 WSI 训练。

**精读核验**：AAAI 2026，Vol. 40, No. 16，pp. 14040–14048；官方仓库与 TCGA-RCC prompt 已核验（2026-09-17）。

## 原文摘要

> While Large Language Models (LLMs) are emerging as a promising direction in computational pathology, the substantial computational cost of giga-pixel Whole Slide Images (WSIs) necessitates the use of Multi-Instance Learning (MIL) to enable effective modeling. A key challenge is that pathological tasks typically provide only bag-level labels, while instance-level descriptions generated by LLMs often suffer from bias due to a lack of fine-grained medical knowledge. To address this, we propose that constructing task-specific pathological entity prototypes is crucial for learning generalizable features and enhancing model interpretability. Furthermore, existing vision-language MIL methods often employ unidirectional guidance, limiting cross-modal synergy. We introduce Multimodal Prototype-based Multi-Instance Learning, in which a frozen LLM generates task-specific descriptions, the vision branch learns instance-level prototypes, and Stereoscopic Optimal Transport integrates both modalities in a unified similarity space.

**摘要因果链**：patch 太多、监督太少、LLM 描述有偏差，所以不让文字单向指导图像；视觉原型和文本原型先各自压缩，再在“实例—原型相似度”层面对齐。

*图源：论文 arXiv HTML，Figure 2。*

### 沿着图从左到右读

1. WSI 先变成实例袋；few-shot 阶段通常使用预提取特征，不重训整张 WSI encoder。
2. T-LPG 生成实例级实体描述与袋级描述：前者定义局部形态原型，后者指导最终聚合。
3. 视觉分支学习 \(K_v\) 个原型并形成相似度表 \(S_v\)；文本分支形成 \(S_t\)。
4. SOT 对齐的是两张相似度表。Sinkhorn 得到传输计划 \(T\)，实例融合分数为 \(\tilde S_j=S_v(j,:)T S_t(j,:)^\top\)，不是直接 concat 特征。
5. Semantic Aggregation 再以袋级语言先验作 query 汇总实例并分类。

### 证据与边界

- RCC、NSCLC、CAMELYON16 的 1/4/16-shot 平均相对 SOTA 提升 2.49% ACC、2.61% AUC、2.15% F1。
- TCGA-RCC 1-shot 完整模型为 71.2 ACC / 87.2 AUC；去视觉原型、把 SOT 换 concat、去语义聚合均下降。
- 固定文本编码器、替换视觉 encoder 后性能明显波动：SOT 不能自动修复两个基础模型原本不对齐的问题。


## 0. 零基础导读：先读这一节

> 这一节只讲直觉，不要求你懂公式。后面的章节用于深入和复现；第一次阅读时，看完本节和第 1 节就可以先停。

### 0.1 把它想成什么？

病理医生既看局部细胞，也背一套疾病词典。Libra-MIL 一边学“典型补丁长什么样”，一边把 LLM 写的病理实体当成文本原型，再在相似度空间里把两边对齐。

### 0.2 它为什么出现？

少样本时普通 MIL 很容易记住噪声补丁；只把类别名塞进 CLIP 又缺少病理实体；单向“文本指导图像”也对不齐两个模态各自的原型。

### 0.3 它到底怎么做？

1. 用预训练编码器提取 patch 特征。
2. 让冻结 LLM 生成袋级形态描述和实例级病理实体。
3. 学习视觉原型，并把实体描述当作文本原型。
4. 用立体最优传输融合两种相似度，再按袋级文本查询聚合。

### 0.4 先认清这些词

- **少样本 / few-shot**：每类只有 1、4 或 16 张切片。
- **原型**：一类形态或实体在特征空间中的中心。
- **SOT**：在视觉原型与文本原型之间做最优传输，再融合相似度。
- **袋级先验**：对整张切片生长方式、边界等的语言描述。

### 0.5 输入和输出

输入是预提取 patch 特征、类别数和任务文本；输出是切片类别，以及可检查的原型相似度。

### 0.6 最容易误解的地方

LLM 生成的实体描述不是金标准。文本分支会偏，所以不能只用图文相似度当最终判决。

**现在只记住一句话：Libra-MIL = 视觉原型和语言实体互相校准后再分类。**

## 1. 三分钟摘要与推荐理由

Libra-MIL 把少样本 WSI 分类写成双原型问题。视觉支路学 \(K_v\) 个实例原型；语言支路用冻结 LLM 生成实例级实体和袋级形态，经 CONCH 文本编码器变成文本原型。两路相似度经 Sinkhorn 最优传输融合成每个实例的标量权重，再用袋级文本做 cross-attention 聚合。

在 TCGA-RCC、TCGA-NSCLC 和 CAMELYON16 的 1/4/16-shot 上，相对当时 SOTA 平均提升 2.49% ACC、2.61% AUC、2.15% F1。消融默认 6 个视觉原型。它适合接在 CLAM / CONCH 之后，看语言先验究竟能补多少少样本信号。

## 2. 问题及研究位置

VLMIL 常把文本当单向查询。少样本时，类别名 prompt 太弱，LLM 实例描述又可能胡编形态。Libra-MIL 的位置是：在 MIL 聚合之前，先把视觉原型和任务实体放进同一个传输问题。

## 3. 核心方法和数据流

```text
WSI patches → 冻结视觉编码器 → 实例特征
任务名 → LLM → 实例实体 / 袋级形态 → CONCH 文本编码器
实例特征 × 视觉原型、文本原型 → 两张相似度表
     → Sinkhorn SOT → 融合权重
袋级文本 query → cross-attention → 切片 logits
```

传输代价是 \(1-\cos(\mathbf{p}_v,\mathbf{p}_t)\)。训练损失是袋级交叉熵；Sinkhorn 迭代可反传。

## 4. 实验、数据集与指标

三套公开数据：TCGA-RCC 925、TCGA-NSCLC 1052、CAMELYON16 399。协议是 1/4/16-shot、五折，报告 ACC/AUC/F1。1-shot 上 RCC 为 71.2 ACC / 87.2 AUC，NSCLC 69.2 ACC，CAMELYON16 62.0 ACC。换视觉编码器（Phikon / GigaPath / UNI）而固定文本编码器时，性能明显波动，说明跨模态空间是否对齐很关键。

## 5. 代码仓库审计

- 评级：**B**。仓库小而完整：`main.py`、`models/mil_ot.py`、`models/text_encoder.py`、`datasets/dataset.py`，并带 TCGA-RCC prompt。
- 需要自行准备 `data_split_json`、标签 CSV、h5 特征和 `conch/pytorch_model.bin`。
- 不提供 Libra-MIL 训练权重；LLM 先验已写成文件，复现时不必再调 GPT。

## 6. 环境、显存与数据

训练在预提取特征上进行，单卡即可。真正成本在 CONCH/UNI 特征与 few-shot 划分是否与论文一致。默认 `--num_vis_prototypes 6`。

## 7. 建议复现路径

1. **最小测试**：用仓库 RCC prompt 和少量 h5，确认 SOT 与分类头能出 logits。
2. **标准实验**：复现 TCGA-RCC 4-shot 或 16-shot。
3. **扩展实验**：打乱或替换实例实体描述，看性能下降是否来自语言先验还是视觉原型。

## 9. 可借鉴思想

- 少样本 MIL 应同时压缩视觉冗余和约束语言幻觉。
- 相似度矩阵可以当成可传输的“第三模态”。
- 袋级文本适合做 query，不适合单独当分类器。

## 10. 局限、风险与课题切入点

跨编码器不对齐时融合会崩；CAMELYON16 1-shot 方差大。可研究可查询原型、实体描述的事实核验，以及与 [FOCUS](https://github.com/dddavid4real/FOCUS) / [WSI-FiVE](12-wsi-five.md) 的关系。
