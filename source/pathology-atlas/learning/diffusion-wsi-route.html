ArtiFusion 适合理解掩码约束采样；RestorePath 适合理解邻域条件与共享潜画布。两者的图像补全均不能证明找回了患者真实的被遮挡组织。

下一层看 BigCell 的全局滑窗和 STREAM 的生成空间选择，再用 QC 与染色评价论文检查“图好看”是否对应任务正确。

四个约束：为什么 WSI 上的扩散模型和自然图像不一样

四个约束决定了这条支线的全部方法选择。理解它们，比记住模型名字更有用。

  • 尺度：单张 WSI 可达千兆像素，无法整体训练或整体采样。所有方法最终都要回答“patch 之间怎么接”——LRDM/ZoomLDM 用嵌入网格 + MultiDiffusion 平均，RestorePath 用随机 patch 扩散 + 距离加权插值。下一节的尺度边界把“图块 / 窗口 / 整片”三层拆开讲。
  • 掩码未知：修复需要一个“哪里坏了”的掩码。ArtiFusion 用阈值法、RestorePath 用 GrandQC，都是外部输入；只有 MedIA 2026 那篇把掩码变成无监督产出。这一环常被当成已知条件，实际是复现里最容易失败的地方。
  • “修好”没有唯一答案：自然图像修复可以对像素，病理图上必须对诊断信息。所以这条支线的评估必须同时有感知/分布指标（FID、LPIPS）与病理特征或下游任务指标（CONCH/UNI 相似度、MIL AUC）。
  • 生成即证据：修出来的细胞结构是模型造的，不是切片里原有的。任何把修复结果喂给下游或阅片的流程，都要保留伪影掩码与“此处为重建”的标注。

SCALE / 先搞清尺度，再读方法

尺度边界：修复的基本单位是窗口，不是整片切片

论文里的“百万像素级大图”指的是从切片上裁下来的一块区域，尺寸 512–4608 像素。没有哪个扩散模型一次处理整张 WSI，RestorePath 也不例外。

同一篇论文里出现的三个尺度，不要混用
尺度典型尺寸代表这一层在做什么
训练图块256 × 256RestorePath、LRDM模型真正学习与推理的单位，潜空间 64 × 64
推理窗口512 – 4608RestorePath 所说的“大图”窗口内部由多个重叠图块协商；窗口之间不共享状态
整张 WSI约 100 000 × 80 000不作为模型输入只能由程序循环调用模型，再把结果贴回原图

1 · 为什么整片进不去

一张 100 000 × 80 000 的 WSI 约 8 Gpx，仅 RGB 原图就 24 GB，单卡放不下。而 4608² 只有 21.2 Mpx、约 64 MB。两者差三个数量级，不是靠调 batch 能补上的。

2 · 显存不跟着图变大，时间才涨

模型每次只处理一个 64 × 64 的潜窗口，整张大图只是躺在显存里的一块数组。实测 2048²、50 步、单卡 4090D 峰值显存 4.6–5.0 GB；换到 4608² 显存几乎不变，但窗口数按面积增长，耗时大约翻 5 倍。

3 · “修整片”是流程，不是模型能力

真实用法是四步循环：GrandQC 找伪影 → 以伪影为中心裁窗口（要包含周围健康组织）→ 修复该窗口 → 用 pyvips 贴回 WSI。贴回属于工程代码，模型本身对“整片”一无所知。

4 · 而且通常不需要修整片

GrandQC 统计伪影只占切片面积的 2–10%。修整片等于把九成算力花在重画本来没坏的组织上，还会改动原始诊断像素，得不偿失。

要警惕的边界：DWI、重叠窗口这类机制只保证一个窗口内部的结构连贯。跨窗口的接缝没有任何模型在做全局优化——所以“整片修复”目前仍是拼接问题，不是生成问题。

先分清用途，再比较模型

五种用途：你想让模型帮你做什么？

这不是五种扩散模型结构，而是五种不同的用途。先看“遇到了什么问题、给模型什么、希望得到什么”，再去读模型细节；同一种模型也可能用于不同任务。

你正在学的主线：先找到受损区域 → 用 RestorePath 尝试修复 → 检查修复后是否有利于病理分析。对应下面的第 2 类 → 第 1 类 → 下游验证；其余三类先作为对照。

1 · 图像修复 · RestorePath 所在的方向

这张切片有一块坏了，能不能补好？

举个例子：扫描时产生气泡，遮住了部分组织。我们想修好这张图，而不是另造一张无关的新图。

给模型什么：一张受损图像，以及标出“哪里需要修”的区域图；这张区域图就叫掩码（mask）。

希望得到什么：尽量保留周围正常区域，把受损区域补成与周围协调的组织图像；是否逐像素保留正常区域，要检查具体实现。

读 RestorePath 时抓住：它怎样利用周围组织补全缺损，又怎样让大图里相邻小块的结果接得上？进入 RestorePath 导读 →

“补得合理”不等于“找回真相”：被遮住的真实细胞并不可见，生成结果不能当作患者原本组织的证明。

对应论文与技术线索

ArtiFusion → ArtiDiffuser → RestorePath；Two-Stage Residual Diffusion 与 LPFM 扩展去模糊/低层增强。PathoGen 虽用 inpainting，但用于合成病变，应放在第 3 类。

2 · 质量检测与定位

先别修，告诉我这张切片哪里有问题

举个例子：拿到一张很大的切片，我们还不知道哪里有气泡、模糊或折叠。修复之前，得先找到这些位置。

给模型什么：一张待检查的切片图像。

希望得到什么：指出哪些位置可能有问题。不同方法可能给出异常分数、用颜色表示可疑程度的热图，或直接标出受损区域的掩码；它们的精细程度并不相同。

与第 1 类的区别：这一类负责找出哪里坏了，不一定修改图像；第 1 类才负责尝试把那里修好。DiffusionQC 是检测方向的例子。

对应论文与技术线索

无监督检测—定位—修复流水线、DiffusionQC、Conditioning Noise；Tissue Detection 与本周的 Artifact Segmentation Benchmark 提供前处理和掩码可靠性的证据。

3 · 图像生成与数据增广

真实训练图不够，能不能再造一些？

举个例子：想训练一个识别肿瘤的模型，但某类组织的样本很少。可以尝试生成一些新样本，补充训练数据；这就叫数据增广。

给模型什么：随机噪声，也可以加上组织类型、病变类型或细胞布局等要求；有些方法从已有图像出发，按要求修改局部。

希望得到什么：新的病理图像或可控修改的训练样本。BigCell 研究大幅病理图像生成；PathoGen 可以在良性组织里合成病变，用于增广。生成样本能否真正改善训练，还需要实验验证。

与修复的区别：修复要补好这位患者的这张图；生成与增广要制造可用的新样本，不要求对应患者原本的组织。所以，PathoGen 虽然也做局部补全，用途仍是合成病变，而不是去除伪影。

对应论文与技术线索

LRDM、ZoomLDM → PixCell/CytoSyn → BigCell；STREAM 改为生成 UNI tokens；CHIS、PathoGen、TopoCellGen、CPathOGen 与 Destroy Me 分别控制结构、病变、布局、干预和伪影。

4 · 染色转换与超分辨率

组织已经拍到了，能不能换种染色或看得更精细？

这里实际上包含两件不同的事，读论文时要分开看。它们都在改造已有图像，而不是专门寻找、填补一块被遮住的区域。

① 虚拟染色：预测另一种染色的样子

给模型什么：例如一张 H&E 图像。希望得到什么：预测同一组织在某种 IHC 染色下可能呈现的图像。HistDiT 属于这个方向。

要分清：这是图像预测，不等于真的对组织做了一次 IHC 实验，也不能仅凭图像逼真就认定染色结果正确。

② 超分辨率：生成更高分辨率的版本

给模型什么：一张分辨率较低、细节不足的图。希望得到什么：分辨率更高的版本。

要检查：新增细节是否保留了可靠的组织形态与诊断信息，而不只是看起来更锐利；生成细节不等于重新扫描得到的真实细节。

对应论文与技术线索

HistDiT、StainDiffuser、LPFM、PixCell 的虚拟 IHC；Histo-Diffusion/SuperDiff、S³-Diff 与 flow matching 邻近路线 CAFlow 的超分。

5 · 辅助分割与表征学习

不一定给人看一张新图，而是帮助分析模型认得更准

举个例子：我们想让模型画出细胞或组织的边界，这叫分割。但人工标注不够，模型自动画出的标注又可能有错。

给模型什么：以修正分割标注为例，输入病理图像及粗糙的区域标注；其他方法也可能在图像特征上学习。

希望得到什么：更可靠的区域标注，或者更适合后续分类的图像特征。“表征”可以先理解为模型用来描述、区分一张图的内部信息，不是一张供人阅片的新图。

CoDiR 的做法：用扩散模型修正不可靠的分割伪标签，再拿这些标注训练分割模型；最终学生模型推理时不需要扩散模块。这里的“伪标签”就是模型自动产生、未经逐一人工确认的标注。

与第 2 类的区别：质量检测主要找哪里是伪影；这一类通常帮助识别哪里是细胞、组织或病变。目的不是把受损图像补好。

对应论文与技术线索

CoDiR 修正低置信伪标签；CMD 做 masked-diffusion 预训练；ZoomLDM 的中间特征用于 MIL。TMEvolve 的反应—扩散图演化只作为概念相邻参考。

TIMELINE / 2023—2026

时间线

  • 2023 起点：修复与生成同时出现 ArtiFusion（MICCAI 2023）首次把 DDPM 用于病理伪影修复，只用无伪影图像训练；DiffInfinite（NeurIPS 2023 D&B）用合成分割掩膜作条件 + 并行随机 patch 扩散生成任意大图；PathLDM 的文本条件路线同期出现（WACV 2024 发表，arXiv 2023-09）。
  • 2024 条件化：用自监督嵌入替代人工标注 LRDM（CVPR 2024）证明 SSL 嵌入足以当条件，并把 patch 模型拼成大图；LatentArtiFusion 把修复搬进潜空间，把推理成本压下来。
  • 2025 分化：修复统一化 vs 生成多尺度 vs 生成基础模型 ArtiDiffuser（MedIA 2025）统一修复与合成并加下游一致性正则；ZoomLDM（CVPR 2025）用倍率感知条件把生成推到 4096×4096；PixCell 把生成推到基础模型规模（PanCan-30M，69,184 张 WSI）。
  • 2026 走向系统：掩码自动化、百万像素与检测可靠性 MedIA 2026 的无监督流水线补上“掩码从哪来”；RestorePath（MICCAI 2026）把修复推到百万像素并要求跨 patch 全局一致；ICEIC 2026 的两阶段残差扩散专治细节丢失；DiffusionQC 把检测也做成扩散模型，而 Tissue Detection 那篇指出检测器的假阳性主要来自前处理的组织检测步骤。

EVALUATION / 三处易错点

评估口径：最容易出错的三处

1 · 指标与条件的独立性

RestorePath 条件用 UNI，FID_C 与 Emb Sim 用 CONCH：是不同编码器，不能仅因同属病理基础模型就断言分数必然被美化。共享训练分布或偏好仍需检查。使用条件编码器自身计算相似度时，尤其需要独立编码器、下游任务或人工判读交叉验证。

2 · 合成伪影 ≠ 真实伪影

ArtiFusion 的测试集伪影来自手工合成方法；RestorePath 的验证掩码来自 failure modes / 气泡合成。这两类实验衡量的是“去合成伪影”，真实扫描伪影需要另测。

3 · FID 口径不统一

同一句“FID”在不同论文里可能指 Vanilla / Crop / CLIP 三种（LRDM 的 BRCA 20× 分别是 6.98 / 15.51 / 7.43）。跨论文比数字前必须先对齐口径，否则结论会反向。

修复保真度

可用指标：L2 / MSE / SSIM / PSNR / FSIM / SRE

已知陷阱：偏袒模糊结果；对细胞级错误不敏感

修复感知质量

可用指标：LPIPS / CLIP-IQA

已知陷阱：伪影类型不同结论反转（透光气泡 vs 不透明墨迹）

病理语义一致性

可用指标：CONCH / UNI / CTransPath 嵌入相似度

已知陷阱：与条件编码器同源时失去独立性

是否真的有临床价值

可用指标：下游 MIL 分类/分割 AUC、注意力是否回到病灶

已知陷阱：需与 Detect-and-Discard 对照，否则分不清“修复”与“剔除”的贡献

REPRODUCTION / 读懂 → 复现 → 改进

复现优先级（面向“读懂机制 → 复现 → 改进”）

  1. 第一档 · ArtiFusion：最小闭环。掩码约束重采样（Eq. 2）、Swin 骨干、T=250、两张 A4000；先跑通修复指标，再补下游分类，确认“掩码大小”这一旋钮对结论的影响。
  2. 第二档 · LRDM：条件化骨架。先复现“SSL 嵌入 → cross-attention → 256 patch”，再上 MultiDiffusion 拼 1024²；条件来源消融（无条件 / ImageNet ViT / CLIP / HIPT）是验证机制是否成立的关键实验，成本可控。
  3. 机制扩展 · ZoomLDM / BigCell / STREAM：分别研究倍率条件、全局速度融合、生成表征空间。作者的多卡与大 batch 是实验配置，不是未经测量的最低门槛；用户算力充足，不因训练规模降级这些方法。
  4. 暂不优先：ICEIC 2026（正文付费墙、仅感知指标）与 MedIA 2026 无监督流水线（无公开代码，需从零实现三段式）。两篇适合作为“读机制、找缺口”的对象，而不是第一批评测目标。
  5. 复现切口：CHIS 检查结构初始化与小波调制；PathoGen 区分病变合成和伪影修复；CoDiR 检查 mask refinement 消融；LPFM 对比粗恢复与扩散细化。优先级取决于机制、协议和资源可达性，而非单纯选择最小模型。
