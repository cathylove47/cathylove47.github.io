DIFFUSION × WHOLE SLIDE IMAGING / SUMMARY

千兆像素的病理图，
扩散模型能做什么。

把“扩散模型用在 WSI 上”拆成四件事：修掉伪影、找出伪影、造出大图、让下游模型不再被伪影骗。这一页汇总已入库的 7 篇主线论文与若干库外补充工作，只保留可以核验来源的事实；每篇标注它解决了哪一环、复现入口在哪、以及已知的失败面。

START HERE / 建议第一步

从 ArtiFusion 起步，
再把 RestorePath 当目标。

ArtiFusion 是这条支线最小的可复现单元：只用无伪影图像训练、掩码约束去噪、两张 RTX A4000(16 GiB) 就能跑，并且报告了完整的下游分类对照。

RestorePath 是当前主线的终点：百万像素级、跨 patch 全局一致，且必须自己解决掩码来源与评估口径。

一、为什么 WSI 上的扩散模型和自然图像不一样

四个约束决定了这条支线的全部方法选择。理解它们，比记住模型名字更有用。

  • 尺度：单张 WSI 可达千兆像素，无法整体训练或整体采样。所有方法最终都要回答“patch 之间怎么接”——LRDM/ZoomLDM 用嵌入网格 + MultiDiffusion 平均，RestorePath 用随机 patch 扩散 + 距离加权插值。
  • 掩码未知：修复需要一个“哪里坏了”的掩码。ArtiFusion 用阈值法、RestorePath 用 GrandQC，都是外部输入；只有 MedIA 2026 那篇把掩码变成无监督产出。这一环常被当成已知条件，实际是复现里最容易失败的地方。
  • “修好”没有唯一答案：自然图像修复可以对像素，病理图上必须对诊断信息。所以这条支线的评估必须同时有感知/分布指标（FID、LPIPS）与病理特征或下游任务指标（CONCH/UNI 相似度、MIL AUC）。
  • 生成即证据：修出来的细胞结构是模型造的，不是切片里原有的。任何把修复结果喂给下游或阅片的流程，都要保留伪影掩码与“此处为重建”的标注。

二、四个赛道

同一批方法在不同任务上被反复借用。按“它在这个赛道里负责哪一环”来读，比按论文年份读更清楚。

赛道 A · 伪影修复（inpainting）

目标：用周围健康组织重建被遮挡或退化的区域，并保持非伪影区不变。

已入库：ArtiFusion（08-23 首个 DDPM 修复）→ ArtiDiffuser（反事实只改伪影区）→ RestorePath（百万像素全局一致）→ Two-Stage Residual Diffusion（结构 + 细节两阶段）。

赛道 B · 伪影检测与定位（QC）

目标：无标注地判出伪影位置，产出像素级掩码，供赛道 A 使用。

已入库：Toward Robust Histopathology Imaging（MedIA 2026，HFM 特征 + 归一化流异常热图 + 无监督分割）。库外补充：DiffusionQC（一类 OOD 检测）、The Effect of Tissue Detection on False Positives（组织检测决定假阳性）。见 §4。

赛道 C · 生成与数据增广

目标：从嵌入、文本或类别条件造出高保真大图，用于扩充训练集或造受控反事实。

已入库：LRDM（SSL 嵌入条件 + 拼 1024²）、ZoomLDM（倍率感知 + 4096²）、TopoCellGen（细胞拓扑）、CPathOGen（受控反事实审计模型）。库外补充：DiffInfinite（掩膜条件 + 并行随机 patch）、PathLDM（文本条件）、PixCell（生成基础模型）、Destroy Me（造伪影做增广）。见 §4。

赛道 D · 染色、超分与切片级表征

目标：解决染色差异与分辨率不足，或把生成模型的中间特征直接当切片表征用。

已入库：ZoomLDM 的 4× 超分与 MIL 特征（U-Net block 3、t=100，病理分型 AUC 94.49 / HRD 85.25）。库外补充：PixCell（生成基础模型 + 虚拟 IHC）、StainDiffuser（虚拟染色）、Histo-Diffusion/SuperDiff、S³-Diff（病理超分）。见 §4。

ArtiFusion

MICCAI 2023 · 修复

首个把 DDPM 用于病理伪影修复的工作：把修复表述为受掩码约束的渐进去噪重采样，只用 2445 张无伪影图像训练。

  • Swin-Transformer 全 U 形骨干 + time token 拼接
  • T=250，Adam lr 1e-4，2×RTX A4000
  • L2/MSE 相对 CycleGAN 降 50%+；推理 30.71 s vs CycleGAN 1.065 s
  • 下游 NCT-CRC 分类：伪影 80.3→修复 92.4（ResNet18）

LRDM

CVPR 2024 · 生成/增广

用自监督嵌入替代逐 patch 人工标注：嵌入经 cross-attention 注入 LDM，再用 MultiDiffusion 平均拼出 1024×1024 大图。

  • 条件：HIPT / iBOT / CTransPath（384·768→512 维）
  • 条件消融 FID：无条件 25.62 → HIPT 6.98
  • 增广使 NCT-CRC patch 准确率 93.8→96.27%；TCGA-BRCA 亚型 1% 数据 AUC 0.725→0.812
  • 直训 1024² 每 epoch 300 h vs patch 法 45 h

ArtiDiffuser

Medical Image Analysis 2025 · 修复 + 合成

反事实扩散：只重建被伪影扭曲的区域，同时把“合成伪影”当作增广，用一个模型统一两条方向。

  • Swin 骨干 + 类别引导 MoE + 类别特定 token
  • 掩码加权损失处理区域不平衡
  • 下游一致性正则：原图与增广图预测保持一致
  • 贡献 723 张跨类别标注 patch（首个）

ZoomLDM

CVPR 2025 · 多尺度生成

一个模型管 8 个倍率：条件从单个嵌入升级为“该 patch 覆盖的 20× 嵌入矩阵”，经 Summarizer 压成定长 token，并另训 CDM 让条件可凭空采样。

  • 倍率 20×→0.15625×；联合采样到 4096×4096、4× 超分
  • 低倍率 patch FID 13.42 vs 单倍率基线 106.14
  • 4096² 上质量落后（CLIP FID 6.75），但 8 min vs 4 h
  • 自陈弱点：均匀区域可见拼缝、低尺度不引导处细结构不连贯

Two-Stage Residual Diffusion

ICEIC 2026 · 修复（失焦模糊）

第一阶段用截断扩散调度快速出“结构对但糊”的粗修复；第二阶段以粗输出与真值的潜空间残差为条件合成细节。

  • 只处理失焦模糊这一类退化
  • 报告指标为 LPIPS 与 CLIP-IQA（感知类，无保真度指标）
  • 两阶段方法的固有风险：粗修复的结构错误无法被第二阶段纠正
  • 正文在付费墙后，站内精读标注为摘要级核验

Unsupervised Artifact Pipeline

Medical Image Analysis 2026 · 检测→定位→修复

把三件事串成一条无监督流水线：HFM 特征上训归一化流得异常热图 → 异常热图 + 无监督语义分割得像素级掩码 → 掩码引导扩散修复。

  • 只用正常训练数据，同时覆盖合成与真实伪影
  • 下游：BCSS 分割与 TCGA-BLCA 肿瘤分期均提升
  • 串联系统的风险：检测漏掉的真伪影永远修不回来
  • 无公开代码（2026-10 核查）

RestorePath

MICCAI 2026 · 百万像素修复

把修复从 patch 级推到百万像素级：以病理基础模型嵌入为条件，用随机 patch 扩散 + 距离加权插值（DWI）+ 自适应引导尺度（AGS）保证跨 patch 一致。

  • 动机数字：TCGA-BRCA 中 63.7% 的 WSI 含 megapixel 级伪影
  • 去 DWI 后 FID_C 29.66 → 110.48（退化最明显）
  • 下游 MIL（Camelyon16 小病灶）：ABMIL 82.3（伪影）→ 90.3（修复），Origin 89.6
  • LPIPS 在 Camelyon16/BACH 上不如 LaMa，结论依赖伪影类型

五、时间线

  • 2023起点：修复与生成同时出现ArtiFusion（MICCAI 2023）首次把 DDPM 用于病理伪影修复，只用无伪影图像训练；DiffInfinite（NeurIPS 2023 D&B）用合成分割掩膜作条件 + 并行随机 patch 扩散生成任意大图；PathLDM 的文本条件路线同期出现（WACV 2024 发表，arXiv 2023-09）。
  • 2024条件化：用自监督嵌入替代人工标注LRDM（CVPR 2024）证明 SSL 嵌入足以当条件，并把 patch 模型拼成大图；LatentArtiFusion 把修复搬进潜空间，把推理成本压下来。
  • 2025分化：修复统一化 vs 生成多尺度 vs 生成基础模型ArtiDiffuser（MedIA 2025）统一修复与合成并加下游一致性正则；ZoomLDM（CVPR 2025）用倍率感知条件把生成推到 4096×4096；PixCell 把生成推到基础模型规模（PanCan-30M，69,184 张 WSI）。
  • 2026走向系统：掩码自动化、百万像素与检测可靠性MedIA 2026 的无监督流水线补上“掩码从哪来”；RestorePath（MICCAI 2026）把修复推到百万像素并要求跨 patch 全局一致；ICEIC 2026 的两阶段残差扩散专治细节丢失；DiffusionQC 把检测也做成扩散模型，而 Tissue Detection 那篇指出检测器的假阳性主要来自前处理的组织检测步骤。

六、评估口径：最容易出错的三处

1 · 指标与条件同源

RestorePath 的 FID_C 与 Emb Sim 都用 CONCH 特征，而训练条件用 UNI；ZoomLDM 的 Embedding Similarity 用 CTransPath，而 5× 条件也是 CTransPath。同族编码器既当条件又当尺子，数值会被系统性美化——必须配合下游任务或人工判读。

2 · 合成伪影 ≠ 真实伪影

ArtiFusion 的测试集伪影来自手工合成方法；RestorePath 的验证掩码来自 failure modes / 气泡合成。这两类实验衡量的是“去合成伪影”，真实扫描伪影需要另测。

3 · FID 口径不统一

同一句“FID”在不同论文里可能指 Vanilla / Crop / CLIP 三种（LRDM 的 BRCA 20× 分别是 6.98 / 15.51 / 7.43）。跨论文比数字前必须先对齐口径，否则结论会反向。

评估目标可用指标已知陷阱
修复保真度L2 / MSE / SSIM / PSNR / FSIM / SRE偏袒模糊结果；对细胞级错误不敏感
修复感知质量LPIPS / CLIP-IQA伪影类型不同结论反转（透光气泡 vs 不透明墨迹）
病理语义一致性CONCH / UNI / CTransPath 嵌入相似度与条件编码器同源时失去独立性
是否真的有临床价值下游 MIL 分类/分割 AUC、注意力是否回到病灶需与 Detect-and-Discard 对照，否则分不清“修复”与“剔除”的贡献

七、复现优先级（面向“读懂机制 → 复现 → 改进”）

  1. 第一档 · ArtiFusion：最小闭环。掩码约束重采样（Eq. 2）、Swin 骨干、T=250、两张 A4000；先跑通修复指标，再补下游分类，确认“掩码大小”这一旋钮对结论的影响。
  2. 第二档 · LRDM：条件化骨架。先复现“SSL 嵌入 → cross-attention → 256 patch”，再上 MultiDiffusion 拼 1024²；条件来源消融（无条件 / ImageNet ViT / CLIP / HIPT）是验证机制是否成立的关键实验，成本可控。
  3. 第三档 · ZoomLDM：最重但产出最广——倍率感知条件 + 多尺度 MIL 特征。3×H100、每卡 batch 200 是硬门槛，建议先做 5×/1.25× 两尺度的小规模版本。
  4. 暂不优先：ICEIC 2026（正文付费墙、仅感知指标）与 MedIA 2026 无监督流水线（无公开代码，需从零实现三段式）。两篇适合作为“读机制、找缺口”的对象，而不是第一批评测目标。
  5. 低成本补充：LatentArtiFusion（同为潜空间修复、代码公开）适合与 ArtiFusion 做“像素级 vs 潜空间”的对照；PixCell 的权重可直接下载，适合当检测（DiffusionQC 的路子）或虚拟染色的现成骨干，不必自己训生成基础模型。
