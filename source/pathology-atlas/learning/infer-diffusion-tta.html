01

跑了什么

按 README 的 DiT 分支跑 main.py +experiment=dit：判别模型 ResNet-18（torchvision 权重），生成模型 DiT-XL/2 256×256，VAE 用 sd-vae-ft-ema；数据为 ImageNet-R 的 6 个类、每类最多 3 张，共 14 张。日志 logs/run1.log（2 张子集）与 logs/run2.log（14 张）。

02

环境与改动

python 3.9，torch 2.0.1+cu118 / torchvision 0.15.2。关键版本是 0.16/0.18 时代的组合：diffusers 0.16.0、transformers 4.28.1、huggingface_hub 0.16.4、datasets 2.14.6、pyarrow 12.0.1、numpy 1.23.5、hydra-core 1.3.2、omegaconf 2.3.0、wandb 0.15.12、timm 0.6.11、accelerate 0.18.0、OpenAI CLIP（git）。坑：diffusers 0.16 必须配 hf_hub<0.20，而新版 datasets 又要 hf_hub≥0.25 且新版 pyarrow 删了 PyExtensionType，只能整套降级。

两处代码改动：(1) diff_tta/models/build.py 加 SD_VAE_PATH 环境变量，复用已下载 VAE 而不走 HF 联网；(2) main.py 的 wandb.init 改为传 OmegaConf.to_container(config, resolve=True)，否则新版 wandb 在原始 OmegaConf 对象上抛 TypeError。

唯一的功能性超参偏离：README 的 input.batch_size=12 在 24 GB 卡上直接 CUDA OOM（DiT-XL 675M 全参数可训 + 激活），降到 2，并把 accum_iter 提到 15 以保持总梯度步 1500 不变；train_steps=100、lr=1e-5、Adam 保持默认。

05

没跑的部分与局限

  1. 小样本：14 张、6 类，前后差异只对应一张图。
  2. 只跑单样本设定：论文最亮的 ImageNet-C 在线结果（如 ConvNeXt-T 16.4→47.4）没有复现，也没有跑 Table 2 的逐损坏对比。
  3. 没跑 CLIP、分割、深度：Table 3/4 全部未复现。
  4. 没有做「只调判别模型 vs 同时调扩散模型」的对照：论文在 ImageNet 系实验里两边都更新，这条是理解其增益来源的关键。
  5. batch 降级：12→2 会改变噪声水平的采样批次结构（论文强调大 batch 降方差很关键），可能低估或高估收益。
  6. 未下载 ImageNet：只从 imagenet-r.tar（1.93 GB）解出 6 个类，避免大流量；因此无法验证 ImageNet 上的 +7.7。
