INFERENCE WALKTHROUGH / NOT A REPRODUCTION

一条命令，
1280 个 TSP-100 实例。

用官方 JAX 实现和 TSP-100 检查点，完全按 scripts/eval/tsp100.sh 的参数跑全量 1280 个实例。两次 mean cost 为 7.755891 / 7.755883，参考最优 7.755851，gap 0.000513% / 0.000403%；论文与 README 报 0.000%。整轮 38–40 s，峰值显存 4520 MiB，代码只改了 Makefile 的编译器。

只跑推理TSP-100 · 1280 实例 · 单 seed
01

跑了什么

只跑 README 的 TSP-100 评测（decoding.tsp），参数与 scripts/eval/tsp100.sh 完全一致：runs=8, cycles=10, sampling_steps=4, two_opt_steps=2, batch_size=128, threads_over_batches=2, augment_level=1，随机 2-opt 步数范围 (25, 75)。数据是 1280 个 100 节点实例（coords + opt_tours，无 opt_costs，代码用 opt_tours 在 CPU 上算最优代价）。

TSP-500/1000、MIS、MCl、CVRP/TSPTW 与训练全部没跑；--decode_intermediate 没开，脚本不落盘解，只打印 cost/gap。

02

环境与改动

独立 conda env（python 3.11）。按 install.sh 装 jax[cuda12]==0.5.0、flax 0.10.4、optax 0.2.4、triton 3.1.0、tensorflow_cpu 2.19、torch==2.6.0+cpu。两处偏差：(1) install.sh 最后把 numpy 钉到 1.26.4 会让 jaxlib 因 ml_dtypes ABI 不匹配而起不来，保留 numpy 2.1.3；(2) 机器无 clang++，lib/Makefile 的编译器换 g++（gcc 9.4/C++17 足够），产物 lib/interface.cpython-311-x86_64-linux-gnu.so。

权重/数据：data/tsp100_concorde_7.75585.npz（HF Rick242420/MaskCO，2.56 MB）、ckpt/tsp100.ckpt（76.5 MB，Google Drive）。运行前设 XLA_PYTHON_CLIENT_PREALLOCATE=false，否则 XLA 预分配整卡。算法与超参未改；1280 = 5 × (128 × 2) 使 threads_over_batches=2 的断言成立，没有改 batch。

结果

两次都在 0.0005% 量级，即 1280 个实例里极少数差 1e-5 相对量；逐 batch 打印的 cost 在 7.7499–7.7599 之间。与论文的 0.000% 属同一水平，跑通且对齐。整轮 38–40 s（5 个 batch × 2 线程，约 7 s/batch），含导入/编译共约 90 s；nvidia-smi 逐进程采样峰值 4520 MiB（XLA 预分配关闭时），batch=128 无需下调。

注意与论文 Table 1 的时间不可直接比：论文 TSP-100 报 6 s 且 8 个算子并行，本走查按脚本顺序执行、单卡共享。差距来源是硬件与并行度，不是算法。

04

没跑的部分与局限

  • 只有一个任务：TSP-500/1000、MIS（RB/ER）、MCl（small/large）都需要各自的数据与 checkpoint（TSP-1000 数据 GB 级），未跑。
  • 单 seed、单配置：没有扫 cycles / sampling_steps，也没有重复 seed 取方差。
  • gap 不是逐例最优证明：最优代价由 opt_tours 算出，0.0005% 说明接近参考解，不等于证明最优。
  • 没有图像产物：该脚本不落盘解，本页只有表格，无样例图。
  • 训练未验证：scripts/train 与自举重标注（GenSCO2/3）没跑。
