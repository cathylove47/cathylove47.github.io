# 04｜MedAgent-Pro：先生成疾病级计划，再按患者证据逐步推理

**论文**：MedAgent-Pro: Towards Evidence-based Multi-modal Medical Diagnosis via Reasoning Agentic Workflow  
**正式发表**：ICLR 2026 主会 Poster  
**类型**：方法论文；规划、医学工具与证据反思的 Agentic workflow  
**阅读范围**：ICLR 官方摘要与 arXiv v3 方法、评估；中文导读，不是全文逐字翻译。

## 0. 这篇解决的是哪种 Agent 问题

它不满足于让 VLM 看完多模态数据就输出诊断，而是要求模型**按计划取得分析证据，再据此更新推理过程**。

框架分两层：

1. **疾病层**：从医学指南生成相对标准化的诊断步骤。
2. **患者层**：根据这个患者实际有哪些数据，调用能执行的工具，逐步分析和反思。

有明确计划、工具动作、返回观测与记忆更新，因此归为 Agent；不是只有一次检索加一次回答的普通 RAG。

## 1. 中文摘要

现代临床诊断需要整合多模态患者信息并进行系统推理。现有视觉语言模型和 Agent 方法常直接输出答案，但缺少定量分析支撑的临床证据。

MedAgent-Pro 提出分层诊断工作流：疾病级的标准计划生成，以及患者级的个性化逐步推理。RAG Agent 检索医学指南，帮助计划与临床标准对齐；患者级推理调用视觉模型等专业工具分析输入，并进行证据驱动的反思和记忆更新。作者在不同解剖区域、影像模态与疾病上评估，并通过消融和专家评价分析框架。

**来源**：[ICLR 2026 官方摘要](https://iclr.cc/virtual/2026/poster/10008810)。本节为中文概述，不把作者的 benchmark 结论扩大为临床有效性证明。

## 2. 疾病层：指南不是直接给最终答案

方法正文使用检索增强生成访问医学知识，再生成临床指导信息与可执行计划。计划步骤要与具体工具函数和参数对应，而不是只写一段“请认真诊断”的自然语言提示。

这一步要区分两类输出：

- **规范信息**：某疾病通常需要查看哪些征象、测量或检查。
- **当前患者证据**：这个患者实际观察到了什么。

检索到“青光眼需要评估某个指标”，不等于这个患者已出现异常。指南支持计划，患者数据支持当前判断。

## 3. 患者层：计划要受到可用数据约束

框架先根据患者的可用数据筛选能执行的步骤；缺少某种检查结果时，不能假装已获得该模态的证据。

| 阶段 | 读取的信息 | 产生的状态 |
|---|---|---|
| 步骤编排 | 标准计划、实际可用模态 | 当前可以执行哪些步骤 |
| 工具分析 | 图像等患者数据、工具参数 | 分割、定位或其他定量输出 |
| 证据反思 | 工具结果、已有记忆 | 更新证据并决定下一步 |
| 最终整合 | 完成步骤中的可靠结果 | 汇总判断与风险信息 |

正文提供 Continue、Terminate、Complete 等步骤状态。阅读时要检查“工具出了结果”和“证据足够可靠”是否被分开处理，以及何时会中止。

## 4. 工具层与证据层不能混为一谈

论文的工具包括视觉分割、grounding 与编码支持等模块，如 MedSAM、Medical SAM Adapter、Cellpose 与 Maira-2。具体工具适配于特定模态和任务，不是一个通用工具可以覆盖所有医学影像。

**可执行性**来自工具接口；**正确性**取决于工具在当前数据上的表现；**诊断相关性**还取决于该输出是否支持当前推理步骤。三者需要分别核验。

同样，数值或掩码并不因进入 Agent 记忆就变成可靠临床事实。错误工具输出可以被后续步骤传播，反思也不能替代独立真值。

## 5. 实验应该如何分组阅读

正文涉及青光眼、心脏疾病、胸片任务以及 NEJM 病例问题，评价使用 balanced accuracy、F1 或 accuracy 等指标。各任务的输入、标签和评估单位不同，不能把它们混成一个统一诊断准确率。

作者通过消融区分计划生成、定量分析与证据式推理的作用。阅读重点是：**在相同底层模型下，加入哪个模块后改变了哪个任务的哪一种指标？**

本导读不引用摘要中的跨任务提升百分比，以免将绝对指标差、相对增益和不同任务口径混用。具体数值应回到[正文对应结果表](https://arxiv.org/html/2503.18968v3)，本站没有独立复算。

## 6. 边界与局限

- **工具覆盖有边界**：缺少适用视觉工具的输入不会因为加上 Agent 名称就得到可靠定量分析。
- **指南检索有边界**：检索遗漏、旧版本指南或不适用人群可能影响后续计划。
- **缺数据不是阴性证据**：不能把跳过某一步解读为排除了对应疾病。
- **逐步推理可能累积错误**：早期错误证据进入记忆后，需要检查后续步骤是否仍可识别或纠正。
- **公开评估不是前瞻临床验证**：专家评价与 benchmark 支持研究结论，不自动支持真实部署。

除工具覆盖限制外，上述项目是本站用于阅读与系统审查的风险分析，不冒充作者已经完成的额外实验结论。
