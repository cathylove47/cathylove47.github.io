## 1. 为什么读这篇

这篇把医学教学中的标准化患者案例转成可执行评测，观察 Agent 在整个就诊过程里如何获取信息、决策和应对患者状态变化。

## 2. 三分钟摘要

MedSP1000 将案例拆成医生初始化信息、患者脚本、环境控制材料和评分规则。被测医生 Agent 与患者及环境闭环交互，评审按轨迹逐项检查诊疗行为。

## 3. 它到底怎么做

1. 初始化案例并向不同角色分配材料。
2. 医生 Agent 询问患者并请求环境信息。
3. 根据行动推进场景与患者状态。
4. 按整段诊疗轨迹检查评分项目。

## 4. 实验与阅读检查

作者报告 1,638 个案例与 24,602 条评分项目；另用临床专家验证案例与模拟质量。

以下是本站建议的精读检查项：

- 核对角色之间的信息隔离，评分材料是否进入医生上下文？
- 分开看案例构建质量、环境执行质量与最终行为评分。
- 将 rubric 完成率与诊断准确率区分，读专家验证子集的结果。

## 5. 与现有路线的联系

与 PatientAgentBench 对读：本篇从标准化患者教学案例出发，后者侧重患者服务与办事工具。

## 6. 本篇阅读产出

做一页对照：写出任务输入、可见信息、可用动作、评分单位和关键基线；选一条原文轨迹，逐步标注动作、返回证据与最终结论的对应关系。这是本站的阅读练习。
